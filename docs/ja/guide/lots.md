# セットと割引

会場でよく使われる割引の言い方は、だいたい次の 3 種類です。

| お客様が聞く言葉 | 摊盒での設定方法 |
| --- | --- |
| 「ポストカード よりどり 3 枚で 20 元」 | **N 点選び放題（よりどり N 点）** のセットを 1 つ |
| 「新刊 + アクスタ セットで 50」 | **固定セット** を 1 つ |
| 「じゃあ 100 ちょうどでいいよ」 | 会計時に **実受取額** を直接変更 |

最初の 2 つはイベントごとに事前に設定しておけば、カートが **自動で** 適用します。3 つ目はその場の値引きなので、売り子が会計時に金額を書き換えるだけです。

:::tip v1.1 の「マイナス価格の商品」はもう不要です
以前は「-5 元の商品を作って割引にする」方法を紹介していました。しかしこれでは割引が販売数の統計に入ってしまい、本物の商品と割引の区別もつきません。
v1.2 からはこのページの 2 つの方法を使ってください。古いマイナス価格の商品は、商品マスタで **無効化** すれば OK です。
:::

## セットを作る

入口：**イベント**（画面表示「展会」）→ **イベントワークベンチに入る**（画面表示「进入展会工作台」）→ **事前準備 · セット**（画面表示「展前 · 套装」）→ **セットを新規作成**（画面表示「新建套装」）。

セットは **イベントごと** の設定です。イベントごとにそれぞれのセットを持ちます。次のイベントでも同じものを使いたいときは、**事前準備 · 商品**（画面表示「展前 · 商品」）→ **前回から取り込む**（画面表示「从上一场导入」）で、商品とセットをまとめて引き継げます。

ドロワーでは次の 4 項目を入力します。

1. **セット名**（画面表示「套装名称」）：お客様がカートで目にする名前です。例：「明信片任选3张20」。
2. **ルール**：`顾客从下面选 [N] 件，一共付 ¥[总价]`（下の候補から N 点選んで、合計 ¥ 総額を支払う）。
3. **何をもって「揃った」とするか**。どちらか 1 つを選びます。
   - 🧩 **固定セット**（画面表示「固定组合（这几样各 1 件凑齐）」、各 1 点ずつ揃える）：「A + B セットで 50」のような場合に。候補の商品は、それぞれ最大 1 点までです。
   - 🔁 **N 点選び放題**（画面表示「任选 N 件（可以拿同款）」、同じ商品も可）：「本 よりどり 3 冊で 100」のような場合に。同じ本を 3 冊選んでも対象になります。
4. **候補商品**（画面表示「候选商品」）：このセットに組み込める商品です。

入力中、ドロワー下部の **お客様がどう選べるか**（画面表示「顾客会怎么拿」）にリアルタイムで試算が表示されます。お客様が選べる一番高い組み合わせ・一番安い組み合わせと、それぞれいくらお得になるかがわかります。
定価より高くなってしまう組み合わせには「比原价贵，不会套用」（定価より高いので適用されません）と表示されます。**保存する前に試算を一度見ておきましょう。**「各 1 点のつもりだったのに、同じ本を 3 冊選んでも割引が効いてしまった」といった事故を防げます。

<p style="text-align: center;"><img src="/images/v1.2/admin-lot-drawer.png" alt="セットの編集：お客様がどう選べるか" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


:::warning 候補商品は同じ所有サークル（荷主）のものに限ります
委託販売で預かっている他サークルの商品を、自分の商品と同じセットに入れることはできません。セットで値引きした分は誰かが負担することになり、
他サークルの商品を値引きするかどうかは売り子が一方的に決められることではないからです。最初の候補商品を選ぶと、他のサークルの商品は自動的にグレーアウトします。
:::

## お客様側にはどう見えるか

お客様がお客様注文画面で商品をカートに入れると、カートが **一番お得なセットの組み合わせを自動で求めます**。お客様が自分で選ぶ必要はありません。複数のセットを同時に適用することもできます。

カートにははっきりとこう表示されます。

```
原价          ¥70（划线显示）
已应用：明信片任选3张20 ×1   −¥10
应付          ¥60
```

（定価 ¥70 に取り消し線、「已应用」＝適用済みのセットと割引額、「应付」＝お支払い額）

合計がなぜ安くなったのかお客様にも分かるので、計算ミスを疑われることもありません。

## 売り子の会計時：セットを外す・実受取額を変える

売り子画面で **準備完了**（画面表示「完成配货」）を押すと、**受取確認**（画面表示「确认收款」）ダイアログが開きます。

<p style="text-align: center;"><img src="/images/v1.2/vendor-receipt-phone.png" alt="受取確認：セットを外す、実受取額を変える、支払い方法を選ぶ" style="max-width: 300px; width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


- **適用済みのセット**（画面表示「已套用的套装」）：セットごとに 1 行ずつ、スイッチ付きで表示されます。お客様に「そのセットはいらない、単品で買います」と言われたら、スイッチをオフにすればその商品は定価で計算されます。
- **実受取額**（画面表示「实收」）：初期値は請求額と同じです。端数切り捨て、キリのいい金額への調整、知り合い割など、その場の値引きはこの数字を直接変えます。
  - 下げた場合：差額は **手動値引き**（手工折让）として記録されます。
  - 上げた場合：**手動値上げ**（手工加价）として記録されます。たとえばシステムに登録していない小物をついでに付けたときなど。

  手動値引きと手動値上げは **すべて自サークルの負担** になります。委託販売のサークルの商品はそのサークル自身の定価で精算されるので、あなたが端数を切っても相手の取り分は減りません。
- **支払い方法（受取チャネル）**（画面表示「收款渠道」）：WeChat Pay（微信）／ Alipay（支付宝）／ 現金（现金）／ その他（其他）。精算時に支払い方法ごとに照合するので、実際のとおりに選んでください。

:::warning 「受取確認」は記帳するだけです
摊盒はどの決済サービスとも連携していません。確認を押す前に、スマホに **本当に入金通知が届いたか** を確かめてください。
:::

## 分けられないセットはどうする？

「セット」は **分けられる** 組み合わせ向けです。5 冊の本を 1 つの袋に入れても、帳簿上はあくまで 5 点のバラ商品で、在庫も 1 点ずつ減り、お客様がそのうち 1 冊だけ買っても問題ありません。

**分けられない** もの（シュリンク済みのギフトボックス、開けたら終わりの福袋など）は、それ自体を独立した商品として登録し、その商品の在庫で出し入れしてください。

## よくある質問

**セットを変更したら、すでに入った注文も変わりますか？**
変わりません。注文には、注文した時点のセット名と価格が保存されています。セットを削除しても過去の注文には影響しません。

**お客様の組み合わせに、あるセットが適用されないのはなぜ？**
主な原因は 3 つです。そのセットの合計が定価より安くない／「固定セット」は各 1 点ずつが条件なのに、お客様が同じ商品を 2 点取っている／もっとお得な組み合わせが別にある。
セットのドロワーの試算を見れば、そのセットがどう適用されるかがはっきりわかります。

**同じ商品を複数のセットに入れてもいいですか？**
大丈夫です。カートは考えられるすべての組み合わせの中から、一番お得なものを選びます。
