# 组网与连接

## 为什么是局域网

漫展现场的网络是出了名的不靠谱：几万人挤在一个场馆，4G / 5G 信号拥堵，场馆 Wi-Fi 时断时续。
依赖云端的收银小程序，在最忙的时候最容易卡住。

摊盒反过来做：**所有数据和服务都在你自己的一台设备（主机）上**，其他设备通过局域网直接连它。
局域网不需要互联网，一个手机热点就够了，不耗流量，也不怕场馆断网。
更多设计理由见[离线与支付问题](./why-offline)。

## 一台主机，多台终端

| 设备 | 做什么 | 怎么打开 |
| --- | --- | --- |
| **主机** | 运行摊盒 App，保存全部数据 | 直接打开 App |
| 点单平板 | 顾客自助点单、展示收款码 | 扫「顾客入口」二维码 |
| 摊主手机 | 接单提醒、确认收款、收摊 | 扫「摊主入口」二维码 |
| 其他电脑 / 平板 | 远程进管理后台 | 扫「管理员入口」二维码 |

主机可以是 Windows 电脑，也可以是 Android 平板。终端只需要一个浏览器，不用装 App。

:::warning 尽量别用手机当主机
手机锁屏、切去收款 App、来电，都可能让系统暂停摊盒的后台服务，这时顾客下单会卡住。
用手机当主机的话，请把它设为常亮、不锁屏，并在电池设置里允许摊盒后台运行。
:::

## 组网步骤

1. 用一台手机打开**个人热点**（不需要开流量）
2. 主机、点单平板、摊主手机**全部连这个热点**
3. 主机打开摊盒，进入「**设置 → 局域网连接**」，点「**获取局域网二维码**」
4. 其他设备用**系统相机**扫对应的二维码（顾客入口 / 摊主入口 / 管理员入口），也可以点二维码下的「点击复制链接」发过去
5. 第一次打开时浏览器会提示「您的连接不是私密连接」，点「**高级 → 继续访问**」，每台设备只需一次，原因见[局域网 HTTPS](./lan-https)

顾客自己不需要扫码：他们只用你摆在摊位上的平板。

:::tip 展会前一晚演练一次
在家把热点、主机、平板、手机全部连一遍，每台设备都接受一次证书。
到了现场，主机换了网络 IP 会变，二维码需要重新获取，但流程你已经熟悉了。
:::

## 连不上时

按顺序排查：

1. **是不是同一个热点？** 最常见的原因是某台设备自动连回了场馆 Wi-Fi 或家里的 Wi-Fi。
2. **Windows 防火墙**：主机第一次启动时会询问，要勾选「专用网络」并允许。漏掉了就去「Windows Defender 防火墙 → 允许应用通过防火墙」给摊盒勾上。需要放行的是 **5141** 端口，5140 只在本机使用，不用管。
3. **IP 变了**：重启热点或换了网络，旧二维码就失效了。回主机重新「获取局域网二维码」。
4. **场馆 / 校园 Wi-Fi**：这类网络通常开了「AP 隔离」，设备之间互相访问不了。换成手机热点。
5. **用微信 / 支付宝扫的码？** 它们内置的浏览器可能拦截自签证书，换系统相机扫。

更多问题见 [FAQ · 网络连接](/faq/network)。
