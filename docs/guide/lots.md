# 套装与优惠

现场常见的优惠说法大致有三种：

| 顾客听到的 | 在摊盒里怎么配 |
| --- | --- |
| 「明信片任选 3 张 20 元」 | 一个**任选 N 件**的套装 |
| 「新刊 + 立牌 一起 50」 | 一个**固定组合**的套装 |
| 「算你 100 整吧」 | 收款时直接改**实收** |

前两种提前在展会里配好，购物车会**自动**套用；第三种是现场临时让价，摊主收款时改一下数字即可。

:::tip v1.1 的「负价格商品」已经不需要了
以前我们教过「建一个 -5 元的商品当折扣」。它会把折扣算进销量统计、分不清真商品和折扣。
v1.2 起请改用本页的两种方式，旧的负价格商品在商品库里**停用**即可。
:::

## 配一个套装

入口：**展会 → 进入展会工作台 → 展前 · 套装 → 新建套装**。

套装是**按展会配的**：每场展会各有自己的套装。下一场想沿用，用「展前 · 商品 → 从上一场导入」把商品和套装一起搬过来。

抽屉里要填四样东西：

1. **套装名称**：顾客会在购物车里看到它，例如「明信片任选3张20」。
2. **规则**：`顾客从下面选 [N] 件，一共付 ¥[总价]`。
3. **怎么算凑满**，二选一：
   - 🧩 **固定组合（这几样各 1 件凑齐）**：适合「甲 + 乙 一起 50」。每种候选商品最多拿 1 件。
   - 🔁 **任选 N 件（可以拿同款）**：适合「本子任选 3 本 100」。同一款拿 3 本也算。
4. **候选商品**：哪些商品可以凑进这个套装。

填的时候，抽屉下方的「**顾客会怎么拿**」会实时算给你看：顾客最多能拿到多贵的组合、最少拿到多便宜的组合、各省多少钱。
比原价还贵的组合会标「比原价贵，不会套用」。**看一眼试算再保存**，能避免「本意是各 1 件，结果顾客拿 3 本同款也享受优惠」这种事。

<p style="text-align: center;"><img src="/images/v1.2/admin-lot-drawer.png" alt="编辑套装：顾客会怎么拿" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


:::warning 候选商品必须属于同一个货主
帮别的社团代卖的商品，不能和自己的商品凑进同一个套装。套装让掉的钱要有人承担，
替别的社团让价不是摊主能单方面决定的。选了第一件候选商品之后，其他社团的商品会自动置灰。
:::

## 顾客那边会看到什么

顾客在点单页加购时，购物车会**自动求出最省的套装组合**，不需要顾客自己选。多个套装可以同时生效。

购物车里写得明明白白：

```
原价          ¥70（划线显示）
已应用：明信片任选3张20 ×1   −¥10
应付          ¥60
```

顾客能看懂为什么总价变低了，就不会怀疑算错。

## 摊主收款时：拆套装、改实收

摊主端点「**完成配货**」后弹出「**确认收款**」：

<p style="text-align: center;"><img src="/images/v1.2/vendor-receipt-phone.png" alt="确认收款：拆套装、改实收、选渠道" style="max-width: 300px; width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


- **已套用的套装**：每个套装一行，带一个开关。顾客说「我不要那个套装，单买就行」，关掉开关即可，这几件按原价计算。
- **实收**：默认等于应收。现场抹零、凑整、熟人让价，直接改这个数：
  - 改低：差额记成**手工折让**；
  - 改高：记成**手工加价**，比如顺手搭了一个没录入系统的小东西。

  手工折让和加价**全部算在本社团头上**。代卖社团的商品仍按它们自己的定价结算，不会因为你抹零而少分钱。
- **收款渠道**：微信 / 支付宝 / 现金 / 其他。结算时按渠道对账，请如实选。

:::warning 「确认收款」只是记账
摊盒不接入任何支付接口。点确认之前，请先确认手机上**真的收到了到账提示**。
:::

## 拆不开的套装怎么办

「套装」适合**拆得开**的组合：5 本书装一个袋子，账上仍然是 5 件散货，库存逐件扣减，顾客单买其中一本也不受影响。

**拆不开**的东西（塑封礼盒、拆了就废的福袋）直接当成一个独立商品录入，按它自己的库存进出。

## 常见问题

**改了套装，已经下过的订单会变吗？**
不会。订单存的是下单那一刻套装的名字和价格。删除套装同样不影响历史订单。

**为什么顾客的组合没有套用某个套装？**
通常有三种原因：该套装的总价不比原价便宜；「固定组合」要求每种各 1 件，顾客拿了 2 件同款；或者存在更省的组合。
在套装抽屉的试算里能看清楚这个套装会怎么被套用。

**同一件商品可以出现在多个套装里吗？**
可以。购物车会在所有可能的组合里挑最省的那个。
