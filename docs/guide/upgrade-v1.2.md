# 从 v1.1 升级到 v1.2

v1.2 把摊盒的账本从「只记库存数字」换成了「每一件货、每一分钱都有来处和去处」的复式账本。
套装优惠、退货、赠送报废、收摊盘点、寄售分账，这些新功能都建立在它上面。

代价是：**旧版的展会和订单没法搬进新账本**。旧数据里只有「现在还剩几件」，
补不出「这件货是从哪来的、卖给了谁、钱进了哪个渠道」。

:::warning 升级前请先读完这一节
- **商品库会自动带过来**：商品、分类、标签、社团、图片、AI 识别用图和识别数据都在。
- **旧的展会、订单、库存不会出现在 v1.2 里**。它们没有被删除，而是原样保留在一个备份文件中，随时可以导出成 Excel。
- **不要在出摊当天、展会进行到一半时升级。** 把手上这场收完、导出好销售报表之后再升级。
:::

## 升级步骤

1. **先把正在进行的展会收尾**：在 v1.1 里导出这场的销售报表（「销售统计 → 下载 Excel」）。
2. **更新 App**：
   - Windows（v1.1.1 及以上）：「设置 → 关于与更新 → 检查更新」，一键下载安装。v1.1.0 需要手动下载安装包覆盖安装，见[自动更新](./auto-update)。
   - Android：从 [GitHub Releases](https://github.com/Academy-of-Boundary-Landscape/ABL-BoothApp/releases) 下载新的 APK 覆盖安装（签名不变，不需要先卸载，**也不要先卸载**，卸载会连数据一起清掉）。
3. **打开 App，登录管理后台**。如果旧库里有展会或订单，会弹出一次「**v1.2 更新了账本模型**」的提示：
   - 点「**导出旧数据为 Excel**」，得到 `legacy_v1_export.xlsx`，里面是旧版全部展会和订单；
   - 点「**知道了**」关闭。
4. 以后想再导出，随时去「**设置 → 历史数据（v1）**」点「导出旧数据为 Excel」。

## 旧数据在哪里

升级时，旧数据库被**改名留存**为 `sale_system.db.v1-backup`，和新数据库放在同一个目录：

- Windows：`%APPDATA%\com.abl.BoothKernel\`
- Android：App 私有目录，只能通过上面的「导出旧数据为 Excel」取出来

摊盒不会自动删除这个文件。

## 升级后先做什么

1. **检查社团归属**。v1.2 的每个商品都属于一个「社团」（货主），结算时按社团分账。
   只卖自己的东西就不用管，商品默认都归「本社团」。帮别的社团代卖的话，先到「**社团**」页建好对方，
   再到「商品库」把他们的商品的「所属社团」改过去。详见[收摊与结算](./closing)。
2. **在新展会里上架商品**。旧展会没有带过来，出下一场时新建展会，在工作台「展前 · 商品」里「从商品库选」。
3. **把「负价格的优惠商品」停用**。v1.1 时我们教过「建一个 -5 元的商品当折扣」，v1.2 有了正式的
   [套装与优惠](./lots)和收款时的「实收」改价，负价格商品会污染统计，请在商品库里停用它。
4. **改掉默认密码**。管理后台顶部会一直提醒，直到你改掉 `admin123` / `vendor123`。

## 以后的升级还会清零吗？

不会。这次清零是账本模型换代的一次性代价。从 v1.2 起，每次升级前 App 都会先给数据库拍一份快照，
升级出错会自动还原，数据库结构只做增量修改。
