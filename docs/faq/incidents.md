# 突发状况

别慌，现场出摊总会有手滑/下错单/设备没电这种事——大多数都能“可逆”。

## 顾客下错单 / 我想取消订单怎么办？

在摊主端「订单 → 待处理」里：

- **不要点「完成配货」**
- 直接点这张订单的 **「取消」**

该订单会被废弃，预留的库存自动返还。

## 手滑误点了“完成”，想反悔怎么办？

别慌：

1. 在管理后台进入这场展会的 **「现场 · 订单」**
2. 找到那笔误操作的订单
3. 在「操作」里选 **「设为已取消」**

系统会把这一单的货和钱两笔账一起冲回去：库存加回、收款渠道的金额扣回、销售额修正。

已取消的订单不能再改状态，也**不能退回「待处理」**。如果只是顾客退了部分商品，用摊主端的「退货」，不要取消整单。

## 主机设备突然没电 / 死机了怎么办？

摊盒采用 SQLite **实时落盘**存储。  
重启设备和软件后，所有商品信息、历史订单和库存数据都会 **自动恢复** 到死机前的那一刻。

:::tip 现场建议
主机端最好配一个移动电源/插线板。不是因为摊盒不稳，而是现场供电就是会不靠谱。
:::

## 顾客买完要退货怎么办？

摊主端「**订单 → 已完成**」找到那一单，点「**退货**」，逐行选退几件、货回现场仓还是进损耗、退款走哪个渠道。
**退货没有撤销**，提交前核对清楚。详见[收摊与结算](/guide/closing)。

## 展会已经结算了，又发现一笔账漏了？

结算后账本冻结，不能再改订单。回家发现的差额，在管理后台「**收摊 · 结算**」里加一条**结算调整**或**垫付**；
对着账单重数收款，就重新提交**收摊清点**。这三项在结算后仍然可以改。
