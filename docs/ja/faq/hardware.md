# ハードウェアの推奨

ひとことで言うと、摊盒は性能はあまり求めませんが、「ずっと動き続けること」は求めます。だからホスト端末選びが大事です。

## スマホでホストを動かせますか？

技術的には可能ですが、**強くおすすめしません**。

理由は現実的なものです。

- 画面ロックやバックグラウンドでプロセスが終了させられやすい
- 発熱でクロックが落ちたり、接続が切れたりする
- 当日はそのスマホで支払いの受け取りや連絡もするので、誤操作しやすい

**ホストにはノート PC かタブレットをおすすめします。**

スマホをホストにすると、画面ロックしたり WeChat / Alipay の受取画面に切り替えたりしたときに、OS が摊盒のバックグラウンドサービスを止めてしまい、お客様の注文が止まることがあります。
どうしても使う場合は、画面を常時点灯・ロックなしに設定し、バッテリー設定で摊盒のバックグラウンド実行を許可してください。

## 端末の性能に要件はありますか？

要件はかなり低めです。

- 最新版の Chrome / Edge が動く Windows PC
- または Android 8.0 以上のタブレット／スマホ

であれば快適に動きます。古い端末を「お客様用の注文端末」にするのも、よい再利用法です。

## 画面はずっと点けておく必要がある？

- ホスト端末は画面を点けたままにするか、電源設定で **スリープしない** にしておくのがおすすめです
- お客様用のタブレットは **画面常時点灯** にしておくと、注文中に急に画面が消えることを防げます

## バーコードリーダーは必要？

必要ありません。お客様注文画面ではカメラで直接バーコードを読み取れます。USB／Bluetooth のバーコードリーダー（キーボードモード）があれば、挿すだけで使え、より速く読み取れます。
Windows でバーコードリーダーを使う前に、入力方式を英語に切り替えてください。[バーコードスキャン](/ja/guide/barcode-scan)をご覧ください。

## Windows で起動するとすぐ落ちる？

v1.2 からはインストーラーに VC++ ランタイムが同梱されています。また、AI 画像認識のランタイム読み込みに失敗しても AI 画像認識が無効になるだけで、アプリが起動できなくなることはありません。
それでも落ちる場合は、**設定 → バージョン情報と更新 → トラブルシューティング**（画面表示「设置 → 关于与更新 → 故障排查」）でログのパスをコピーし、`booth.log` を交流グループか GitHub Issue に送ってください。
