# 收摊与结算

v1.2 起，一场展会有明确的终点：摊主在摊主端走完**收摊向导**，系统生成**结算单**并冻结账本。
结算单回答「账怎么算」：每个社团的货去了哪、该分多少钱、我应该转给谁多少。

:::warning 结算单上的数字是账本算出来的，不是系统核对过的
摊盒不接入支付接口。「我应转给 XX」是**应转数**，不代表已经转过；「实际到手」是你自己数完录进去的。
系统没有能力核对任何一笔到账，转完账请自己留好凭证。
:::

## 先搞清楚：社团 = 货主

每个商品都属于一个**社团**，也就是货主：谁的货卖了钱，钱就算谁的。

- 「**本社团**」有且只有一个，就是你自己。商品不指定社团时，默认归本社团。
- 帮朋友的社团代卖（寄售），就在侧栏「**社团**」里新建对方，再到「商品库」把他们的商品的「**所属社团**」改成对方。
- 改「所属社团」只影响**之后**上架到展会的货，已经上架的保持原归属。

只卖自己东西的摊主不用管这一节，结算单上只会有「本社团」一块。

## 现场：赠送、报废、退货

这三件事都在**摊主端**做，会直接写进账本，结算单里能看到。

### 赠送与报废

货不在摊上了，但不是卖掉的：摊主端 → **库存** → **登记赠送/报废**。

- **赠送**：亲友拿样、随手塞的小礼物。默认**货主自己承担**，结算单上只显示送了几件。
  如果这份礼物算你请客，打开「**这笔我自掏（按原价补给货主）**」，结算时这笔钱会从你这边补给货主。
- **报废**：损坏、脏污、缺件，不能再卖了。只动库存，不动钱。

登记错了可以在下方列表里**撤销**，货会回到现场仓。

### 退货

摊主端 → **订单** → **已完成** → 找到那一单点「**退货**」：

- 按订单行逐行选退几件。同一商品可能因为套装归属被拆成两行，退哪一行由你决定。
- 每行选退回的货去哪：**回现场仓（还能卖）**或**进损耗（已损坏）**。
- **退款渠道**默认与收款渠道相同。现金收的就现金退，否则收摊清点对不上。
- **实际退款**默认是所选各行实付之和，可以改低，**不能超过顾客实付**。

**退货没有撤销。** 退错了只能再开一张反向的单，或者在结算时补一条结算调整。

## 收摊向导：四步

展会结束时，在**摊主端**切到「**收摊**」tab（手机在底部 tab 栏）。
向导按顺序走四步，当前在第几步由账本状态决定，**中途退出、换台设备再进来都不会丢进度**。

<p style="text-align: center;"><img src="/images/v1.2/vendor-closing-phone.png" alt="摊主端收摊向导" style="max-width: 300px; width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


### ① 清点订单

还有**待处理**（顾客下了单、摊主还没确认收款）的订单时，后面三步都进不去。
逐单点「**完成**」（会弹出收款窗口）或「**取消**」。确定剩下的全是废单时，可以点「**全部取消**」。

:::warning 这一步的按钮点了立即生效
「取消」「全部取消」没有二次确认，点之前看清楚。
:::

### ② 盘点（可以跳过）

把每个商品现场实际剩多少件数一遍，填进「实数」框。

- 输入框**不预填账面数**。「我数了，和账面一致」与「我没数」是两件事，一致的也请照着填一遍。
- 顶部显示「已盘 X / Y」，打开「**只看未填**」可以只看还没填的行。
- 填到一半切走也没关系，已填的数字会作为草稿保留在这台设备上。
- 实数和账面不一致时，提交前会列出差异让你确认。**盘点差异提交后不能直接撤销。**

实在没时间盘点就点「**跳过盘点**」。结算单会标注「**未盘点，剩余数为账面推算**」，不会把账面数当成实数。

### ③ 带回

确认把现场仓里剩下的货全部带走，点「**确认带回**」。之后每个商品的现场仓都清零。

### ④ 结算

如果还有拦路的问题（例如现场仓没清空），会以 ⚠ 列出来，「结束展会」按钮是灰的。
没有问题就点「**结束展会**」：

- 展会状态变成「**已结算**」，账本冻结；
- 「收摊」tab 原地变成这场展会的**结算单**，摊主可以直接查看和导出。

## 结算单怎么看

入口有两个，内容完全一样：

- 管理后台：展会工作台 → **收摊 · 结算**
- 摊主端：已结算展会的 **收摊** tab

<p style="text-align: center;"><img src="/images/v1.2/admin-settlement.png" alt="结算单：两个货主分块" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>

每个货主一块：

| 行 | 含义 |
| --- | --- |
| 【货】 | 带去 N → 卖出 / 赠送 / 报废 / 带回 / 现场仓，以及盘点差异。点「展开明细」看每个商品 |
| 【钱】 | 商品原价 − 套装折让 − 手工折让（或 + 手工加价）→ 净额；有退货、自掏赠品时也列在这里 |
| 【我垫付】 | 你替这个社团垫的钱，从应转里扣掉 |
| 【调整】 | 结算调整，逐条列出名目 |
| **我应转给 X** | 最后该转给这个社团的钱 |

底部是「实际到手合计」「Σ 我应转给」「摊主留存」三个总数。

点「**导出 Excel**」得到 `settlement_<展会名>.xlsx`，四个 sheet 的说明见[导出与复盘](./export)。

:::tip 页面顶部出现红色警示条时
「这张结算单和账本对不上，先别急着导出」说明某笔账记错了。先核对，或者到交流群反馈，确认无误后再导出。
:::

## 结算之后还能改什么

冻结之后，下单、改单、补货、赠送报废、退货、盘点、带回、再次结算都会被拒绝。
**只有三件事**仍然可以在管理后台「收摊 · 结算」里补：

- **垫付**：替某个社团先掏的钱（摊位费、打印费），回家翻出收据再补。它会从「我应转给」里扣掉。
- **结算调整**：回家才发现要多给谁、或者谁要多给你的钱。方向用按钮选「我要多给他们 / 他们要多给我」，金额只填正数。
- **收摊清点**：对着微信 / 支付宝账单和现金盒，把**每个用过的收款渠道**的实际到手都报一遍。
  和账面的差额由摊主自己承担，不进任何货主的结算。想推给某个货主，就加一条结算调整。

这三项会改变结算单，所以结算单底部写着「**账本最后变动于 …**」。发给社团之前看一眼时间，确认是最新的一份。

:::danger 删除展会不受冻结保护
在展会列表里删除一场已结算的展会，会连同它的全部订单和账本流水一起**永久删除，无法恢复**。
想留着对账的展会，不要删。
:::
