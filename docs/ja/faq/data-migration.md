# データの安全と移行

このページでは 4 つのことを扱います。データはどこにあるのか、端末の乗り換え方、Excel 出力に何が入っているか、そして v1.1 からアップグレードしたあと古いデータはどこへ行ったのか、です。

## データはどこに保存される？ 安全ですか？

すべてのデータ（画像・台帳・在庫）は、あなたの **ホスト端末のローカルデータベース** に保存されます。
クラウドサーバーは一切ないので、売上データはあなた以外の誰にも知られません。

## 新しい端末に乗り換えるとき、データはどう移す？

**商品マスタ**（画面表示「商品库」）ページ下部の「商品データパック（.boothpack）」（画面表示「商品数据包（.boothpack）」）パネルで **.boothpack をエクスポート**（画面表示「导出 .boothpack」）を押すと、すべての商品情報・所属サークル・画像がまとめてダウンロードされます。
このファイルを新しい端末に送り、同じパネルで **.boothpack をインポート**（画面表示「导入 .boothpack」）を押す（またはファイルをドラッグ＆ドロップする）だけです。

:::warning `.boothpack` に入るのは商品マスタだけ
イベント・注文・台帳は **含まれません**。端末を乗り換える前に、記録として残したいイベントは精算書と売上集計を出力しておいてください。
:::

## 出力した Excel には何が入っている？

2 種類あり、答えてくれる問いが違います。

- **売上集計**（**当日 · 統計**（画面表示「现场 · 统计」）→ Excel レポートをダウンロード）：商品ごとに何点売れていくらになったか。成績表として使うのに向いています
- **精算書**（**撤収 · 精算**（画面表示「收摊 · 结算」）→ Excel を出力）：各サークルの取り分、誰にいくら送金すべきか（送金すべき額）、支払い方法ごとの帳簿上の額と実際の額。委託販売の分配はこちらを見てください。

詳しくは[エクスポートと振り返り](/ja/guide/export)をご覧ください。

## v1.2 にアップグレードしたら、古いイベントや注文はどこへ？

v1.2 では台帳が新しくなり、旧バージョンのイベントと注文は移行されていませんが、**削除もされていません**。`sale_system.db.v1-backup` にそのまま残っています。
**設定 → 過去データ（v1）**（画面表示「设置 → 历史数据（v1）」）で **旧データを Excel に出力**（画面表示「导出旧数据为 Excel」）を押せば取り出せます。商品マスタは自動で引き継がれています。
詳しくは[v1.1 から v1.2 へのアップグレード](/ja/guide/upgrade-v1.2)をご覧ください。
