# 5 分钟极速上手

摊盒的核心理念是：**不依赖场地网络**，只用一个热点就能让多台设备在局域网里协同工作。
下面按现场的真实流程，从 0 搭好一个能用的出摊系统。

:::tip 从 v1.1 升级过来？
v1.2 换了新账本，旧的展会和订单不会迁移（可以导出成 Excel）。请先看[从 v1.1 升级到 v1.2](./upgrade-v1.2)。
:::

:::tip 摊盒有三种角色
- **管理后台**：展会前后用。录商品、建展会、配套装、看订单和统计、看结算单
- **顾客点单页**：摆在摊位前。展示商品、自助下单、显示收款码
- **摊主端**：拿在摊主手里。新单提醒、确认收款、退货、赠送报废、收摊
:::

---

## 你需要准备什么

### 最小配置（推荐）
- 设备 A：装了**摊盒 App** 的平板，展前展后当管理后台，展会中当顾客点单页
- 设备 B：有浏览器的手机，扫码连接，当摊主端接单

### 高人流配置
- 主机：电脑（放桌下 / 摊位后方）
- 点单页：1～2 台平板（摆在摊位前当电子菜单）
- 摊主端：1～3 台手机（摊主和社员同时接单）

## Step 1：安装与基础配置

<div style="text-align: center;">
  <img src="../images/help/p1.png" alt="Step 1" style="max-width: 200px;">
</div>

1. 从 [GitHub Releases](https://github.com/Academy-of-Boundary-Landscape/ABL-BoothApp/releases) 下载并安装摊盒（Windows 选 `.exe`，Android 选 `.apk`）
2. 打开 App，点「**进入管理后台开始配置**」，输入管理员密码（默认 `admin123`）
3. 左侧栏是：**展会 / 商品库 / 社团 / 设置 / 使用教程**

:::info 第一次打开先做一件事
到「**设置 → 安全设置**」改掉管理员密码和默认摊主密码。默认密码写在公开的教程里，
同一个 WiFi 里的任何人都能用它登录。改掉之前，后台顶部会一直提醒你。
:::

---

## Step 2：录入商品库

从侧栏进入 **商品库**，在「添加新商品到仓库」里逐个录入：

- **商品编号**（必填，唯一，建议 A01、B02 这样的短编码）、**商品名称**、**默认价格**
- 可选：**商品分类**（点单页左侧按它分组）、**标签**（按角色、系列筛选）、**商品预览图**
- 可选：**商业条码**。商业本、官方周边有 JAN / ISBN 的可以填上，点单时就能[扫码加购](./barcode-scan)
- 可选：**所属社团**。不选就归「本社团」。帮别的社团代卖的，先去「社团」页建好对方再选，结算时会自动分开算

:::tip 商品库是可复用的模板
找一天把社团所有制品集中录进去，以后每场展会只需要挑选上架。
录好后可以在商品库底部导出 `.boothpack`，发给帮你出摊的朋友导入。
:::

## Step 3：创建展会、上架商品

<div style="text-align: center;">
  <img src="../images/help/p2.png" alt="Step 3" style="max-width: 200px;">
</div>

1. 侧栏 **展会** → 「**新建展会**」：填名称、日期、地点；可以设一个本场的**摊主密码**（留空就用全局默认摊主密码）
2. 上传**微信收款码**和**支付宝收款码**（可选，传一张也行）。顾客下单后，点单页会展示它们
3. 点展会卡片进入**展会工作台**。顶部是状态条「筹备 → 进行中 → 已结算」，下面的标签页按「展前 / 现场 / 收摊」分组
4. 在 **展前 · 商品** 上架这一场要卖的东西：
   - 「**从商品库选**」：多选商品，在「待上架」表里填售价（默认商品库价格）和库存（留空按 0，之后可以「补货」）
   - 「**从上一场导入**」：不是第一次出摊的话，勾选上一场的商品和套装一次搬过来
5. 需要套装优惠（任选 N 件、合购价）的，到 **展前 · 套装** 配置，见[套装与优惠](./lots)
6. 准备好了，在状态条上点「**开始展会**」。展会变为「进行中」，点单页和摊主端才能找到它

## Step 4：组网（离线局域网）

<div style="text-align: center;">
  <img src="../images/help/p3.png" alt="Step 4" style="max-width: 200px;">
</div>

多台设备靠局域网同步，最稳的方式是**开个人热点**：

1. 用任意一台手机打开热点（不需要开流量）
2. **所有设备都连这个热点**
3. 主机（装 App 的那台）保持摊盒打开
4. 在主机上进入「**设置 → 局域网连接**」，点「**获取局域网二维码**」，会出现三个二维码：
   **顾客入口**、**摊主入口**、**管理员入口**
5. 其他设备用**系统相机**扫对应的码（不要用微信 / 支付宝扫，可能被拦截）
6. 第一次打开会看到「您的连接不是私密连接」的警告，点「**高级 → 继续访问**」即可，每台设备只需一次（原因见[局域网 HTTPS](./lan-https)）

:::warning 不要让设备连场馆 Wi-Fi 或校园网
场馆 Wi-Fi 拥堵、断连频繁；校园网等大型网络通常开了客户端隔离，设备之间根本连不上。
Windows 主机第一次启动时会询问防火墙，请允许「专用网络」。
:::

## Step 5：摆好设备

<div style="text-align: center;">
  <img src="../images/help/p4.png" alt="Step 5" style="max-width: 200px;">
</div>

浏览器访问和 App 里的功能几乎一样，所以哪台设备当主机并不重要，按现场需要分配就行。

### 点单平板
用途：摆在摊位前展示商品、顾客自助下单、展示收款码。

1. 用「顾客入口」二维码打开（或在主机 App 里点侧栏底部「顾客端」）
2. 点正在进行的展会，进入点单页
3. 没人操作 60 秒后会回到「欢迎光临」的吸引屏，并清空购物车

<p style="text-align: center;"><img src="/images/customer.png" alt="点单平板：购物车自动套用套装" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


顾客也可以用「📷 拍照识别」（需要先配置 [AI 拍照识别](./vision-search)）或「▦ 扫码」（见[条码扫描](./barcode-scan)）找商品。

### 摊主手机
用途：新单提醒、确认收款、配货。

1. 用「摊主入口」二维码打开，选择展会
2. 输入摊主密码（本场设了专属密码就用它，否则用默认摊主密码 `vendor123`）
3. 底部有三个 tab：**订单 / 库存 / 收摊**

<p style="text-align: center;"><img src="/images/v1.2/vendor-orders-phone.png" alt="摊主端：订单" style="max-width: 300px; width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>


新订单进来时手机会响提示音。请调大媒体音量，并在页面上随便点一下（浏览器要求页面被点过才能出声）。

:::tip 典型的现场流程
1. 顾客在平板上选商品 → 「去结算」→ 「确认下单」→ 平板展示收款码
2. 摊主手机响起 → 配货 → 听到到账提示后点「**完成配货**」→ 选收款渠道、「**确认收款**」
3. 需要替顾客点单时，摊主端点「**去点单**」，点完再点「**回摊主端**」
:::

## Step 6：收摊结算

<div style="text-align: center;">
  <img src="../images/help/p5.png" alt="Step 6" style="max-width: 200px;">
</div>

展会结束时，在**摊主端**切到「**收摊**」tab，跟着向导走四步：**清点订单 → 盘点 → 带回 → 结算**。
走完之后展会冻结，「收摊」tab 变成这场的**结算单**。每一步的细节见[收摊与结算](./closing)。

之后在管理后台的展会工作台里：

- **现场 · 统计**：销售额曲线和各商品销量，「下载 Excel 报告」得到**销售汇总**，回答「卖了什么」
- **收摊 · 结算**：结算单，「导出 Excel」得到每个社团该分多少、我应转给谁多少，回答「账怎么算」

**寄售分账看结算单，不看销售汇总。** 两者的区别见[导出与复盘](./export)。

## FAQ：现场常见问题

### Q1：一定要联网吗？
不需要。摊盒的设计目标就是**离线局域网可用**，热点就是网络。只有「检查更新」和第一次下载 AI 识别模型需要联网。

### Q2：能同时连多少台设备？
主要取决于热点设备的性能和现场干扰。1 台主机 + 2 台平板 + 3 台手机都没问题。

### Q3：掉线会怎样？
掉线期间设备收不到最新订单和库存。恢复连接后自动重连，刷新页面即可。数据都在主机上，不会丢。

### Q4：如何备份和导出数据？
- 商品库：在「商品库」页底部导出 `.boothpack`
- 展会数据：导出销售汇总和结算单（Excel）。注意 Excel 不能导回 App
