# 硬件建议

一句话：摊盒对性能要求不高，但对“持续在线”要求高，所以主机的选择很关键。

## 我可以在手机上运行主机端吗？

技术上可以，但 **强烈不推荐**。

原因很现实：

- 锁屏/后台容易杀进程  
- 发热会降频甚至断联  
- 现场你还得拿它收款/沟通，很容易误操作

**推荐用笔记本电脑或平板作为主机。**

用手机当主机时，锁屏或切到微信 / 支付宝收款页，系统可能暂停摊盒的后台服务，顾客下单会卡住。
一定要用的话，设为常亮、不锁屏，并在电池设置里允许摊盒后台运行。

## 对设备性能有要求吗？

要求很低：

- 任何能运行最新版 Chrome/Edge 的 Windows 电脑
- 或 Android 8.0+ 的平板/手机

都可以流畅运行。老旧设备当“顾客点单机”也是很好的废物利用。

## 需要一直亮屏吗？

- 主机端建议保持亮屏，或在电源设置里设为 **不休眠**
- 顾客端平板建议设置 **屏幕常亮**，避免顾客点单时突然黑屏

## 需要扫码枪吗？

不需要。点单页可以直接用摄像头扫条码。有 USB / 蓝牙扫码枪（键盘模式）的话插上即用，扫得更快。
Windows 上用扫码枪前请切到英文输入法。见[条码扫描](/guide/barcode-scan)。

## Windows 上打开就闪退？

v1.2 起安装包自带了 VC++ 运行库，AI 识别的运行库加载失败也只会关闭拍照识别，不会让 App 打不开。
如果仍然闪退，请到「设置 → 关于与更新 → 故障排查」复制日志路径，把 `booth.log` 发到交流群或 GitHub Issue。
