# 高级技巧

这里是一些“官方不一定做复杂功能，但你可以用小技巧实现”的玩法。

## 如何给顾客打折？

两条路，覆盖现场绝大多数说法：

**① 套装**——在「套装与优惠」里配好「从这几样里任选 N 件，总价 XX」，顾客的购物车会自动套用最省的那一种，并写明省了多少。

**② 一口价**——点「完成配货」时直接改「实收」。差额记成手工折让，全部算在本社团头上，帮别的社团代卖的商品仍按它们自己的定价结算。改高也可以，用于往上凑整或顺手搭了个没录入的小东西。

## 支持“捆绑销售”或“套装”吗？

因为如果系统性引入套装，那么记账/记库存的逻辑会变得更繁琐，建议直接录入一个名为“XX套装”的新商品，并设置好打包价。  
这样在统计销量时也能清楚地知道卖出了多少个套装。

## 我该如何处理售罄的商品？

在库存不足或售罄时，顾客端会自动将该商品置灰并禁止下单。  
你无需手动隐藏或下架商品。
