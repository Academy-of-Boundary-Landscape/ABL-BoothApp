# トラブル対応

慌てなくて大丈夫です。当日の会場では、操作ミスや注文間違い、バッテリー切れはつきもの。ほとんどは「元に戻せる」ようになっています。

## お客様が注文を間違えた／注文をキャンセルしたい

売り子画面の **注文 → 未処理**（画面表示「订单 → 待处理」）で：

- **品出し完了**（画面表示「完成配货」）は **押さない**
- その注文の **キャンセル**（画面表示「取消」）を直接押す

その注文は破棄され、確保されていた在庫は自動で戻ります。

## うっかり「完了」を押してしまった。取り消したい

慌てずに：

1. 管理画面でそのイベントの **当日 · 注文**（画面表示「现场 · 订单」）を開く
2. 誤操作した注文を探す
3. **操作**（画面表示「操作」）から **キャンセル済みにする**（画面表示「设为已取消」）を選ぶ

システムがその注文の「モノ」と「お金」の 2 つの記帳をまとめて打ち消します。在庫は戻され、支払い方法ごとの金額は差し引かれ、売上も修正されます。

キャンセル済みの注文は状態を変更できず、**未処理に戻すこともできません**。お客様が一部の商品だけ返したい場合は、注文全体をキャンセルせず、売り子画面の **返品**（画面表示「退货」）を使ってください。

## ホスト端末のバッテリーが切れた／フリーズした

摊盒は SQLite に **リアルタイムで書き込み** ています。
端末とアプリを再起動すれば、商品情報・注文履歴・在庫データはすべて、フリーズ直前の状態に **自動で復元** されます。

:::tip 当日のアドバイス
ホスト端末にはモバイルバッテリーか電源タップを用意しておくのがおすすめです。摊盒が不安定だからではなく、会場の電源はそもそも当てにならないからです。
:::

## 購入後にお客様が返品したいと言ってきた

売り子画面の **注文 → 完了済み**（画面表示「订单 → 已完成」）でその注文を探し、**返品**（画面表示「退货」）を押します。行ごとに何点返すか、商品を会場在庫に戻すか廃棄（損耗）にするか、返金をどの支払い方法で行うかを選びます。
**返品は取り消せません。** 確定前によく確認してください。詳しくは[撤収と精算](/ja/guide/closing)をご覧ください。

## 精算が終わったあとで、記帳漏れが見つかった

精算後は台帳が凍結され、注文は変更できなくなります。帰宅後に見つかった差額は、管理画面の **撤収 · 精算**（画面表示「收摊 · 结算」）で **精算調整** または **立替** を 1 件追加してください。
明細を見ながら受取額を数え直した場合は、**入金照合** を再提出します。この 3 つは精算後も変更できます。
