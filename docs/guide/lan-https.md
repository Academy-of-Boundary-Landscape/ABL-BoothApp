# 局域网 HTTPS 与首次接受证书

摊盒 v1.1.1 起，**摊主之外**的所有局域网访问（顾客点单页、摊主接单页、管理员控制台）都改走 HTTPS（`https://<主机IP>:5141`）。这是为了让 AI 拍照识别功能能够工作 —— 浏览器规定摄像头只能在 HTTPS（或 localhost）下使用。

## 为什么会看到"您的连接不是私密连接"

摊盒使用了**自签名证书**，仅供局域网内你自己的设备使用，没有也不可能向公共证书机构申请（公网 CA 不会给私有 IP 签证书）。所以浏览器初次见到会警告，这**不是恶意攻击**，是预期行为。**每台设备一次性接受即可**，之后该设备访问就不会再问。

## 各浏览器接受方法

### Chrome / Edge（Windows、Android）

1. 看到红色警告页"您的连接不是私密连接"
2. 点击页面上的「**高级**」按钮
3. 出现额外文字后，点击「**继续前往 192.168.x.x（不安全）**」
4. 进入页面，今后该设备访问无需再确认

### Safari（iPad / iPhone）

1. 看到警告页"此连接非专用"
2. 点击「**显示详细信息**」
3. 滑到底，点击「**访问此网站**」
4. 系统再次确认，点「**访问网站**」

### 小米 / 华为 / OPPO / 一加 系统浏览器

绝大部分国产系统浏览器走 Chrome 内核，路径同上：高级 → 继续访问。

### 微信 / QQ 内浏览器

❌ **不要用**这些扫码访问。它们对自签证书的处理不一致，可能完全无法继续。

**正确做法**：用微信扫码后，长按链接复制 → 用系统浏览器粘贴打开。或更直接：用相机 / 二维码扫描 app 扫，会自动调起系统浏览器。

## IP 变了怎么办

漫展现场的 WiFi 与你家里 / 公司不同，主机 IP 会变。摊盒会在启动时自动检测并**重新生成证书**——已接受过老证书的设备会再看一次警告，再点「高级 → 继续」即可。

**漫展前一晚的建议流程：**
1. 主机连上漫展现场 WiFi
2. 启动摊盒
3. 用每台需要访问的设备扫一次「管理员入口」二维码 → 接受证书警告
4. 之后整个漫展期间都不用再处理

## 我能不能直接关掉警告？

不能。这是浏览器为了你的安全做的强制提示，绕开它需要"安装本地 CA 根证书到系统信任链"，每台设备的安装流程不同且复杂，得不偿失。

## 摊主自己的桌面摊盒会被影响吗

**不会**。Tauri 桌面应用通过 `http://127.0.0.1:5140` 直连后端，走的是回环 HTTP，没有 HTTPS 警告，速度最快。

## 防火墙首次拦截

Windows 主机第一次启动 v1.1.1 摊盒时，系统会弹防火墙询问对话框。**勾选「专用网络」并允许**，否则 LAN 设备无法连接到 5141 端口。

如果忘记勾选或误点拒绝：
- 控制面板 → 系统和安全 → Windows Defender 防火墙 → 允许应用通过防火墙
- 找到「摊盒」/「BoothKernel」条目，勾选「专用」
- 应用 → 重启摊盒

## 端口被占了怎么办

5140（HTTP 回环）和 5141（HTTPS LAN）是固定端口。如果与你机器上其它软件冲突：
- 5140：通常不会冲突（仅本地）
- 5141：少数 IIS / 抓包软件可能用。临时关闭即可

如果确实长期冲突，目前需要修改源码后重新构建（`tauri.conf.json` + `lib.rs`），未来版本会做成可配置。
