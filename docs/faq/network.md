# 网络连接

这类问题出现频率最高，但也最好解决：**99% 都是“没连同一个热点”或“被防火墙拦了”。**

:::tip 先按顺序排查（真的有效）
1. **同一个 Wi-Fi/热点**：主机端（电脑/平板）和手机必须连同一个热点  
2. **Windows 防火墙**：是否允许“摊盒/Booth-Kernel”通过？  
3. **热点重启导致 IP 变了**：重启热点后请在主机「设置 → 局域网连接」**重新获取局域网二维码**
:::

## 其他设备怎么连上主机？App 里没有「扫一扫连接」？

- 这是对的，我们的架构是:
    - **主机端（Host）**：运行摊盒 App，负责业务逻辑和数据存储
    - **客户端（Client）**：局域网内任意设备用浏览器访问主机提供的网页
- 所以是**主机出码、别的设备扫**：在主机「**设置 → 局域网连接**」点「**获取局域网二维码**」，
  用平板 / 手机的**系统相机**扫「顾客入口」或「摊主入口」。
- 点单页上的「▦ 扫码」是扫**商品条码**加购用的，和连网无关，见[条码扫描](/guide/barcode-scan)。

## 手机扫码后显示“连接超时”或网页无法打开？

这是最常见的问题，请按顺序排查：

1. **检查热点**：确保主机（电脑/平板）和扫码的手机连的是同一个 Wi-Fi/热点  
2. **防火墙拦截**：Windows 主机请检查防火墙是否允许“摊盒”通过，或尝试暂时关闭防火墙验证  
3. **IP 变动**：如果重启过热点，IP 地址可能会变，请在主机端重新 **「获取局域网二维码」**
4. **证书警告没点过去**：第一次访问会提示「连接不是私密连接」，点「高级 → 继续访问」，见[局域网 HTTPS](/guide/lan-https)

:::warning 小经验
漫展现场很多人会下意识连场馆 Wi-Fi，但那玩意儿经常抽风，还可能隔离设备互访。**热点局域网才是最稳的。**
:::

## 没有网络 / 信号差能用吗？

**完全可以。** 摊盒是“离线优先”的设计。  
推荐用一台设备开启 **手机热点** 组建局域网，其他设备连接它即可：

- **不需要连接互联网**
- **不消耗流量**

## 我是校园网 / 公共 Wi-Fi，设备连不上？

公共网络通常开启了 **AP 隔离**（禁止设备间互相访问）。  
解决办法也很简单：**请务必使用热点来组建网络**，这是漫展现场最稳妥的方案。

## 中途断网了，数据会丢吗？

**不会。** 只要主机端（App 端）没有关闭，数据就一直存在。  
重新连接网络后，手机端刷新页面即可恢复之前的状态。
