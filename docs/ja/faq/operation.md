# 当日の運営

このページでは、支払い用 QR コードの置き方、注文の締め方、通知音、複数端末での連携など、「当日の会場で出くわすこと」にお答えします。

## 支払い用 QR コードはどう設定する？ 複数の支払い方法に対応してる？

イベントワークベンチに入り、ページ上部の **編集**（画面表示「编辑」）を押すと、**WeChat Pay と Alipay の QR コードを別々にアップロード** できます。

- 2 枚アップロードした場合：お客様の会計画面に WeChat / Alipay の 2 つのコードが **横並び** で表示され、お客様は使うアプリに合わせて読み取れます
- 1 枚だけの場合：コードが **1 つ中央に** 表示されます
- 自分で画像を合成する必要はもうありません。v1.1 から 2 枚のアップロードに対応しています

## お客様が支払ったら、注文は自動で完了しますか？

**しません。**
プライバシー保護と金融リスク回避のため、摊盒は決済 API に接続していません。

「Alipay／WeChat で入金されました」という通知音が聞こえたら、売り子画面でその注文の **品出し完了**（画面表示「完成配货」）を押し、支払い方法（受取チャネル：WeChat / Alipay / 現金 / その他）を選んでから **入金確認**（画面表示「确认收款」）を押してください。

在庫はお客様が注文した時点ですでに確保されています。「入金確認」で記録するのは **お金の側の記帳**、つまりどの支払い方法で、実受取額がいくらか、です。あくまで記帳であり、お金が本当に届いたかをシステムが照合することはありませんし、その手段もありません。

## 新しい注文が来たら音で知らせてくれますか？

**知らせてくれます。** 売り子画面のスマホは、新しい注文を受け取ると通知音を鳴らします。

聞こえない場合は、まず次を確認してください。

- スマホが **マナーモード／おやすみモード** になっていないか
- **メディア音量** が小さすぎないか
- 売り子画面を開いたあと、**ページを一度タップしたか**：ブラウザはページが一度操作されるまで音を鳴らせません。**更新**（画面表示「刷新」）を一度押せば大丈夫です

**在庫**（画面表示「库存」）や **撤収**（画面表示「收摊」）タブに切り替えていても、通知は通常どおり届きます。

## 複数人／複数端末で同時に頒布できますか？

できます！ 同じテザリングにつないでいれば、たとえば次のような使い方ができます。

- タブレット 2 台を「注文受付機」として置く
- 売り子 3 人がそれぞれスマホを持って「品出し機」にする

すべてのデータはリアルタイムで同期されます。

## 売り子がお客様の代わりに注文できますか？

できます。売り子画面の上部で **注文画面へ**（画面表示「去点单」）を押すとお客様注文画面に入り、お客様の代わりに商品を追加して注文できます。終わったら上部の **売り子画面に戻る**（画面表示「回摊主端」）を押して、そのまま入金確認を続けます。
商品にバーコードがあれば、注文画面の「▦ スキャン」（画面表示「▦ 扫码」）やバーコードリーダーでさらに素早く追加できます。[バーコードスキャン](/ja/guide/barcode-scan)をご覧ください。

## お客様に値引き／端数切り捨てをするには？

事前に決めておく割引は[セット](/ja/guide/lots)で設定しておけば、お客様のカートに自動で適用されます。
その場での値引きは、「入金確認」（画面表示「确认收款」）で **実受取額**（画面表示「实收」）を直接書き換えてください。差額は手動値引きとして記録されます。

## 人にあげた・壊れた商品はどう記録する？

売り子画面の **在庫**（画面表示「库存」）タブ → **贈呈／廃棄を登録**（画面表示「登记赠送/报废」）で記録します。記録しないと、撤収時の棚卸しで棚卸し差異として表示されます。[撤収と精算](/ja/guide/closing)をご覧ください。
