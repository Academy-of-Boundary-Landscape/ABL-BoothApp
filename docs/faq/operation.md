# 现场运营

这一页主要回答：收款码怎么放、订单怎么结、提示音、多设备协同这些“现场会遇到的事”。

## 怎么设置收款码？支持多渠道吗？

进入展会工作台，点页头的"编辑"，可以 **分别上传微信和支付宝** 两张收款码。

- 上传两张：顾客结算页会自动**并排显示**微信 / 支付宝两个码，顾客用哪个 App 扫哪个
- 只上传一张：页面**单码居中**显示
- 无需再自己拼图，v1.1 起系统已支持双码上传

## 顾客付款后，系统会自动完成订单吗？

**不会。**  
为了保护隐私、也为了规避金融风险，摊盒不接入支付接口。

你听到“支付宝/微信到账”的提示后，在摊主端这张订单上点 **「完成配货」**，选好收款渠道（微信 / 支付宝 / 现金 / 其他），再点 **「确认收款」**。

库存在顾客下单时就已经预留，「确认收款」记下的是**钱的那一笔账**：哪个渠道、实收多少。它只是记账，系统不会、也没有能力核对钱是否真的到了。

## 有新订单时会有声音提示吗？

**有的。** 摊主手机端在收到新下单请求时会播放提示音。

如果你没听到，优先检查：

- 手机是否处于 **静音/勿扰**
- **媒体音量** 是否太小
- 打开摊主端后**在页面上点过一下没有**：浏览器要求页面被点过才能播放声音，点一下「刷新」即可

切到「库存」「收摊」tab 时提醒照常工作。

## 可以多人 / 多设备同时摆摊吗？

支持！只要连入同一个热点，你可以：

- 放 2 台平板作为“点单机”
- 让 3 位摊主都拿着手机作为“配货机”

所有数据会实时同步。

## 摊主可以帮顾客点单吗？

可以。摊主端页头点「**去点单**」进入点单页，替顾客加购、下单；点完点页头的「**回摊主端**」回来接着收款。
商品有条码的话，点单页的「▦ 扫码」或扫码枪能更快加购，见[条码扫描](/guide/barcode-scan)。

## 怎么给顾客打折 / 抹零？

提前配好的优惠用[套装](/guide/lots)，顾客购物车会自动套用。
现场临时让价，在「确认收款」里直接改「**实收**」，差额记为手工折让。

## 送人、弄坏了的货怎么记？

摊主端「**库存**」tab →「**登记赠送/报废**」。不记的话，收摊盘点时会显示成盘点差异。见[收摊与结算](/guide/closing)。
