# コミュニティとオープンソース

ここでは主に、ダウンロード先、アップデート方法、フィードバック窓口、そしてオープンソースに関するよくある疑問を扱います。

## 最新版はどこでダウンロードできますか？

公式の配布先は **GitHub Releases** ページだけです。
有料ダウンロードや「導入代行（有料）」を持ちかけてくるものはすべて詐欺です。ご注意ください。

## 自動更新できますか？

Windows 版は v1.1.1 からワンクリックの自動更新に対応しています。アプリが自分で新しいバージョンを確認し、確認後にダウンロードとインストールを行います。
詳しくは[自動更新（中国語）](/guide/auto-update)をご覧ください。

Android 版は OS の制約により、引き続き APK を手動でダウンロードしてインストールする必要があります。

## バグを見つけた／提案がある。どこに送ればいい？

- プログラムのエラー：GitHub リポジトリで **Issue** を立てていただくのを強くおすすめします（開発者が追跡・修正しやすいため）
- 使い方の疑問・雑談：**ユーザー交流グループ** へのご参加を歓迎します

## 開発者ですが、コードで貢献できますか？

**大歓迎です！**
小さなバグの修正でも、新しい機能モジュールの開発でも、あなたの貢献はより多くのサークルの助けになります。
**Pull Request** をお待ちしています。

## ソフトを改変して再配布（さらには販売）してもいい？

このプロジェクトは **MIT ライセンス** なので、改変・再配布の自由は確かにあります。
ただ、「同人頒布のハードルを下げる」ための無料ツールとして、商用ソフトに仕立てて販売することは **強くおすすめしません**。

原作者の表記を残し、オープンソースの精神を尊重してください。
