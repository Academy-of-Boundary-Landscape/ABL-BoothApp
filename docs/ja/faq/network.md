# ネットワーク接続

いちばんよく聞かれる問題ですが、いちばん簡単に解決できる問題でもあります。**99% は「同じテザリングにつながっていない」か「ファイアウォールにブロックされている」のどちらかです。**

:::tip まずは順番に確認（本当に効きます）
1. **同じ Wi-Fi／テザリング**：ホスト（PC／タブレット）とスマホは、必ず同じテザリング（ホットスポット）につないでください
2. **Windows ファイアウォール**：「摊盒／Booth-Kernel」の通信が許可されていますか？
3. **テザリングの再起動で IP が変わった**：テザリングを再起動したら、ホストの **設定 → LAN 接続**（画面表示「设置 → 局域网连接」）で **LAN 用 QR コードを取得し直して**（画面表示「获取局域网二维码」）ください
:::

## ほかの端末はどうやってホストにつなぐの？ アプリに「スキャンして接続」がない？

- それで正しいです。摊盒の構成はこうなっています：
    - **ホスト（Host）**：摊盒アプリを動かし、業務ロジックとデータ保存を担当
    - **クライアント（Client）**：LAN 内の任意の端末が、ブラウザでホストの提供する Web ページを開く
- つまり **ホストが QR コードを出し、ほかの端末が読み取る** 形です。ホストの **設定 → LAN 接続**（画面表示「设置 → 局域网连接」）で **LAN 用 QR コードを取得**（画面表示「获取局域网二维码」）を押し、
  タブレット／スマホの **標準カメラ** で「お客様用入口」（画面表示「顾客入口」）または「売り子用入口」（画面表示「摊主入口」）を読み取ってください。
- お客様注文画面の「▦ スキャン」（画面表示「▦ 扫码」）は、**商品のバーコード** を読み取ってカートに入れるためのもので、ネット接続とは関係ありません。[バーコードスキャン](/ja/guide/barcode-scan)をご覧ください。

## スマホで QR コードを読んだら「接続タイムアウト」になる／ページが開けない？

いちばん多いトラブルです。次の順に確認してください。

1. **テザリングを確認**：ホスト（PC／タブレット）と読み取ったスマホが、同じ Wi-Fi／テザリングにつながっているか
2. **ファイアウォール**：Windows ホストの場合、ファイアウォールで「摊盒」が許可されているか確認するか、一時的にファイアウォールを切って試してください
3. **IP の変更**：テザリングを再起動した場合 IP アドレスが変わることがあります。ホストで改めて **LAN 用 QR コードを取得**（画面表示「获取局域网二维码」）してください
4. **証明書の警告を通過していない**：初回アクセス時に「この接続ではプライバシーが保護されません」と表示されます。「詳細設定 → アクセスする」を押してください。[LAN HTTPS（中国語）](/guide/lan-https)を参照

:::warning ちょっとした経験談
イベント会場では、つい会場の Wi-Fi につなぎがちですが、よく不安定になるうえ、端末同士の通信を遮断していることもあります。**テザリングで組んだ LAN がいちばん安定します。**
:::

## ネットがない／電波が悪くても使えますか？

**まったく問題ありません。** 摊盒は「オフラインファースト」の設計です。
1 台の端末で **スマホのテザリング** をオンにして LAN を作り、ほかの端末をそこにつなぐだけでOKです。

- **インターネット接続は不要**
- **データ通信量も消費しません**

## 学内ネットワーク／公衆 Wi-Fi で、端末同士がつながらない？

公衆ネットワークでは多くの場合 **AP アイソレーション**（端末同士の通信を禁止する機能）が有効になっています。
解決方法は簡単で、**必ずテザリングでネットワークを組んでください。** イベント会場ではこれがいちばん確実です。

## 途中でネットが切れたら、データは消えますか？

**消えません。** ホスト（アプリ側）を閉じない限り、データはずっと残っています。
ネットワークにつなぎ直したら、スマホ側でページを再読み込みすれば元の状態に戻ります。
