# 数据安全与迁移

这一页关心四件事：数据在哪里、怎么换机、导出 Excel 有啥、从 v1.1 升级后旧数据去哪了。

## 我的数据存储在哪里？安全吗？

所有数据（图片、账本、库存）均存储在你 **主机设备的本地数据库** 中。  
我们没有任何云端服务器，你的营业额数据除了你自己没人知道。

## 换了新设备，怎么迁移数据？

在「**商品库**」页底部的「商品数据包（.boothpack）」面板点 **「导出 .boothpack」**，会把所有商品信息、社团归属和图片打包下载。
把这个文件发到新设备，在同一个面板点 **「导入 .boothpack」**（或直接把文件拖进去）即可。

:::warning `.boothpack` 只含商品库
展会、订单、账本**不在**里面。换设备前，把要留底的展会导出结算单和销售汇总。
:::

## 导出的 Excel 包含哪些内容？

有两种，回答的问题不同：

- **销售汇总**（「现场 · 统计」→ 下载 Excel 报告）：各商品卖了多少、卖了多少钱，适合当成绩单；
- **结算单**（「收摊 · 结算」→ 导出 Excel）：每个社团该分多少、我应转给谁多少、各收款渠道的账面和实际。寄售分账看这一份。

详见[导出与复盘](/guide/export)。

## 升级到 v1.2 之后，旧的展会和订单去哪了？

v1.2 换了新账本，旧版的展会和订单没有迁移进来，但**没有删除**：它们原样保留在 `sale_system.db.v1-backup` 里。
在「**设置 → 历史数据（v1）**」点「**导出旧数据为 Excel**」即可取出。商品库是自动带过来的。
详见[从 v1.1 升级到 v1.2](/guide/upgrade-v1.2)。
