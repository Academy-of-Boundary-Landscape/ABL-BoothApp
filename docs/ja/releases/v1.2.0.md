# 摊盒 v1.2.0

> v1.1 で摊盒は「使える」ようになり、v1.2 で **帳簿がきちんと合う** ようになりました。
> このバージョンでは帳簿を作り直しました。商品 1 点・お金 1 円ごとに、出どころと行き先があります。セット割引、返品、贈呈・廃棄、撤収時の棚卸し、委託販売の精算は、すべて新しい帳簿の上に成り立っています。

:::warning アップグレード前に必ずお読みください：古いイベントと注文は移行されません
商品マスタは自動で引き継がれますが、v1.1 の **イベント・注文・在庫は v1.2 には表示されません**。これらはバックアップファイルにすべて保存されており、
アップグレード後に初めて管理画面にログインしたとき、ワンクリックで Excel に出力できます。**イベントの最中にはアップグレードしないでください。**
詳しくは [v1.1 から v1.2 へのアップグレード](/ja/guide/upgrade-v1.2) を参照してください。
:::

## 主な更新

### 📒 新しい帳簿：商品もお金も両側から記録

以前の在庫はただの数字で、売れたら減らし、キャンセルされたら増やすだけでした。計算が合わなくなっても原因を追えませんでした。
今は、注文・受取・返品・贈呈・棚卸しのたびに **貸借が必ず一致する** 仕訳を 1 件ずつ記録します。商品がどの在庫からどの在庫へ移ったか、お金がどの支払い方法からどのサークルへ入ったか、1 件も漏らしません。

- 受取時に **支払い方法（受取チャネル）** を選びます（WeChat Pay／Alipay／現金／カスタム）。撤収時には支払い方法ごとに照合します
- 「注文を完了」は相変わらず **記帳するだけ** で、システムが入金を確認したという意味ではありません。この点は変わっていません

### 🎁 セットと割引

- イベントごとに **セット** を設定：「ポストカード よりどり 3 枚で 20」（同じ商品も可）や「新刊 + アクスタ セットで 50」（各 1 点ずつ揃える）
- お客様のカートが **一番お得な組み合わせを自動で求め**、「已应用：XX 套装 −¥10」（適用済み：XX セット −¥10）と明記します
- 売り子は会計時に **セットを 1 つずつ外したり**、**実受取額** を直接変えたり（端数切り捨てや値上げ）できます。差額は手動値引きとして記録され、委託販売サークルの取り分には影響しません
- セットの設定中に「お客様が最大／最小でどう選べるか」をリアルタイムで試算し、設定ミスを防ぎます
- v1.1 の「マイナス価格の商品を割引代わりにする」方法を置き換えます

詳しくは [セットと割引](/ja/guide/lots) を参照してください。

### 🧾 撤収と精算

- 売り子画面に **撤収ウィザード** を追加：注文の整理 → 棚卸し → 持ち帰り → 精算。途中で抜けても進捗は消えません
- **精算書**：各サークルの商品がどうなったか、純額はいくらか、自分は誰にいくら送金すべきかが 1 枚で分かります。4 シートの Excel に出力できます
- **委託販売の精算**：商品は「サークル」ごとに所属し、預かった他サークルの商品は自動で別々に精算されます
- **返品**（行ごと、一部返品可、返金方法の変更可）、**贈呈／廃棄** の登録、**立替**、**精算調整**、**入金照合**
- 精算後は帳簿が凍結され、立替・精算調整・入金照合の 3 つだけを帰宅後に追記できます

詳しくは [撤収と精算](/ja/guide/closing) を参照してください。

### ▦ バーコードスキャン

- お客様注文画面でカメラを使い **バーコードを連続で読み取ってカートに追加**。市販のバーコード（JAN / ISBN）も自作の番号ラベルも読み取れます
- USB / Bluetooth の **バーコードリーダー** に対応。挿すだけで使えます
- 商品フォームで「扫码填入」（スキャンして入力）でバーコードを入力できます
- すべてオフラインで動作し、どのネットサービスにも依存しません

詳しくは [バーコードスキャン](/ja/guide/barcode-scan) を参照してください。

### 🧭 管理画面と売り子画面を再設計

- **イベントワークベンチ**：イベントに入ると上部に「準備中 → 開催中 → 精算済み」（筹备 → 进行中 → 已结算）のステータスバーがあり、タブは「事前準備／当日／撤収」（展前 / 现场 / 收摊）でグループ分けされています
- **事前準備**：「商品マスタから選ぶ」（从商品库选）でまとめて出品。「**前回から取り込む**」（从上一场导入）で商品・販売価格・セットを一度に引き継げます
- サイドバーは「イベント／商品マスタ／サークル／設定／使い方」（展会 / 商品库 / 社团 / 设置 / 使用教程）に固定。旧「コンソール」（控制台）と「アプリについて」（关于）は「設定」に統合
- **売り子画面** は「注文／在庫／撤収」（订单 / 库存 / 收摊）の 3 タブ構成に。スマホでは下部のタブバーになります。タブを切り替えても新規注文の通知は止まりません
- 売り子画面の「**注文へ**」（去点单）、お客様注文画面の「**売り子画面へ戻る**」（回摊主端）で、タブレットでの代理注文をワンタップで行き来できます
- 売り子がそのイベントの精算書を直接見られます
- 注文一覧に返金済みの金額と、行ごとの返品済み数量を表示
- アプリ全体でコンポーネントと配色を統一し、タブレットのお客様注文画面とスマホの売り子画面をどちらもレイアウトし直しました

## 修正と改善

- Windows で VC++ ランタイムがないと **起動直後に落ちる** 問題を修正：インストーラーにランタイムを同梱し、AI モデルの読み込みに失敗しても AI 画像認識だけをオフにして、アプリ全体には影響しないようにしました
- Android の AI 認識の「自動」モードを CPU で動かすように変更（実測で NNAPI はこれらのモデルではかえって遅かったため。設定で手動選択は引き続き可能）
- 開店時に未処理の注文がないと、**最初の新規注文で通知音が鳴らない** 問題を修正
- LAN 上のブラウザから Excel 出力に失敗する問題を修正
- AI 画像認識の一連の問題を修正：差分インデックス作成で画像が抜ける、再構築に失敗しても「完了」と表示される、商品パック取り込み後にインデックスが作られない、アルバムの縦長画像が引き伸ばされる
- 認識が使えないときは、お客様注文画面の「拍照识别」（AI 画像認識）の入口をグレーアウトし、押してからエラーになることがないようにしました
- カメラを閉じた後もインジケーターが点いたまま（カメラが解放されていない）の問題を修正
- `.boothpack` の取り込みを強化：データフォルダの外に書き込もうとするエントリを拒否
- 管理画面で、出荷時の初期パスワード（`admin123` / `vendor123`）の変更を常に促すように
- アプリ全体の表示文言を中国語に統一（以前は一部の入力欄のプレースホルダーが英語の「Please Input」でした）
- アップグレードのたびにデータベースのスナップショットを自動で取り、アップグレードに失敗したら自動で元に戻します

## アップグレードの注意点

- **Windows**：v1.1.1 の方は「设置 → 关于与更新」（設定 → アプリ情報と更新）からワンクリックで更新できます。v1.1.0 の方はインストーラーを手動でダウンロードしてください
- **Android**：新しい APK をダウンロードして上書きインストールしてください。**先にアンインストールしないでください**（アンインストールするとデータが消えます）
- 初回起動後は [v1.1 から v1.2 へのアップグレード](/ja/guide/upgrade-v1.2) を読んで、古いデータの出力とサークルの所属の確認をしてください
- LAN アクセスは引き続きポート 5141（HTTPS）を使います。証明書と QR コードの使い方は変わりません
