# 图片显示

图片是“顾客愿不愿意下单”的关键，但也最容易被原图体积坑到。

## 商品图片无法显示或加载很慢？

按这个顺序处理：

1. 检查图片文件名是否包含特殊符号（建议用 **纯数字或英文** 命名）  
2. 局域网传输带宽有限，建议把单张图片压缩到 **500KB 以内**  
   不要直接上传 10MB 的高清原图（现场会很痛苦）

## 我可以自定义界面样式吗？

在「**设置 → 外观**」里可以调：

- **界面模式**：浅色 / 深色
- **商品图比例**：3:4 竖版或 1:1 方形，影响点单页的卡片比例和上传图片时的默认裁剪
- **品牌主色**：几种预设配色

点单页右上角的「⚙」还能调商品卡片大小、拖动调整商品顺序（顺序只保存在这台设备上）。
