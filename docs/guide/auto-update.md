# 自动更新

摊盒 v1.1.1 起支持一键更新，不再需要手动下载安装器。

## 如何更新

1. 打开「**控制台**」
2. 找到「**检查更新**」入口
3. 摊盒会访问 GitHub 询问是否有新版本
4. 若有新版本，会展示更新日志，点击「**下载并安装**」
5. 下载完成后会出现两个按钮：
   - 「**立即重启**」—— 弹出确认后关闭应用、自动安装、自动重启（< 10 秒）
   - 「**稍后重启**」—— 安装包已落地，但保留当前会话；下次你手动重启摊盒时生效
6. 重启后版本就更新了

## 使用建议

- **正在摆摊时不要点「立即重启」**。重启会清空内存里未保存的订单、未提交的编辑。等下班收摊后再更新是最安全的。
- 网络不稳或在流量有限的移动热点下，建议等回到稳定 WiFi 再更新。单次更新包通常在 10–50 MB 之间。
- 如果下载中途中断，关掉弹窗重新打开再试一次即可，不会占用磁盘空间。

## 什么时候用不了自动更新

- **Android 版**：暂不支持一键自动安装，仍需从发布页下载 APK 手动安装。按钮会显示为「前往下载」。
- **没网**：会显示「网络错误」或「检查过于频繁」。连上网或等几分钟重试。
- **更新包校验失败**：说明下载内容不完整或 GitHub release 被意外篡改。按钮会提示你改走「前往下载」手动获取安装器。

## 从 v1.1.0 升级到 v1.1.1

v1.1.0 没有自动更新能力，**第一次升级到 v1.1.1 仍需手动下载**。进入官方 GitHub Releases 页面（[点此前往](https://github.com/Academy-of-Boundary-Landscape/ABL-BoothApp/releases/latest)）下载最新的 `.exe` 安装器，运行并覆盖旧版。

**从 v1.1.1 起**，之后的版本都能走一键更新，不会再出现这一次的手动步骤。

## 隐私说明

- 摊盒只有在你主动点「检查更新」时才联网
- 联网对象只有 GitHub（获取版本号和安装包）
- 不会上报任何使用数据、设备信息或展会数据
- 你的订单、商品、展会信息始终只保存在本机
