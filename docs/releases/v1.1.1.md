# 摊盒 v1.1.1

> v1.1.0 之后的小步迭代，重点修了几个真实场景的硬伤 + 给摊盒接上了一键自动更新。

## 主要更新

### 🔄 Windows 一键自动更新

控制台「检查更新」从过去"打开 GitHub 让你手动下载"升级为完整的下载 → 验签 → 安装 → 重启闭环。从 v1.1.1 起后续版本都不需要再手动重装。

- 下载有进度条，安装前会弹确认对话框（避免现场误触重启）
- 安卓端暂仍走原来的"前往发布页手动下载"流程

### 🔒 局域网 HTTPS（顾客端拍照识别终于能用）

摊盒同时监听 HTTP（仅本机）+ HTTPS（局域网）两个端口，自签证书自动生成。这解决了顾客端平板浏览器之前调不起摄像头的根本问题——浏览器规定 `getUserMedia` 只在 HTTPS / localhost 下可用，之前 LAN HTTP 的 v1.1 顾客拍照识别功能在浏览器场景实质上不可用。

- 摊主每台设备首次访问会看到一次"证书警告"，点「高级 → 继续访问」即可，每台只需一次
- 详细说明见 `docs/guide/lan-https.md`

### ⚡ Boothpack 导入提速 10 倍

70MB+ 的 `.boothpack` 从平板浏览器导入时，原先会卡 30-60 秒甚至崩溃。诊断到是 Tauri 内置 IPC 在大体积二进制传输时阻塞主线程，改为本地 HTTP 直传后**3-5 秒搞定**。后端也加了详细的分阶段日志便于后续诊断。

## 新功能

### ✂️ 图像裁剪 + 比例偏好

新建 / 编辑商品上传图片时，自动弹出裁剪框（自由 / 1:1 / 3:4），AI 识别图批量上传支持每张依次裁剪、可跳过使用原图。主题设置新增「商品图比例」开关切换 3:4（默认竖版）/ 1:1（方形），影响商品网格展示比例和裁剪默认值。

## Bug 修复

- 控制台修改管理员密码 / 默认摊主密码报"API Route not found"——前后端路径不匹配，已修
- 主机同时连 WiFi + 开热点时二维码给出 WiFi IP（手机连不上），现在优先返回热点 IP
- 顾客点单页小号卡片 + 3:4 模式价格被压成 `15...`，调整尺寸保证完整显示
- 主题设置「商品图比例」按钮选中态文字看不清，改成开关式 toggle，颜色随主题
- Android 构建因 updater 权限误放共享 capability 而失败，已分离到 desktop-only

## 升级须知

- **v1.1.0 → v1.1.1**：v1.1.0 还没自动更新能力，**首次升级到 v1.1.1 仍需手动下载**。从 v1.1.1 起后续版本就能一键更新了
- **首次访问 LAN 页面会有红屏证书警告**：私网自签证书的预期行为，不是恶意攻击。每台设备点过一次就不再问
- **Windows 防火墙首次启动会询问 5141 端口入站**——记得勾「专用网络」并允许，否则手机连不上
