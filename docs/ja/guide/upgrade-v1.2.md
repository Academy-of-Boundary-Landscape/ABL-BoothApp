# v1.1 から v1.2 へのアップグレード

v1.2 では、摊盒の帳簿を「在庫の数字だけを記録する」ものから、「商品 1 点・お金 1 円ごとに出どころと行き先がある」複式簿記の帳簿に切り替えました。
セット割引、返品、贈呈・廃棄、撤収時の棚卸し、委託販売の精算といった新機能は、すべてこの帳簿の上に成り立っています。

その代わり、**旧バージョンのイベントと注文は新しい帳簿に移せません**。古いデータには「今何点残っているか」しかなく、
「この商品はどこから来て、誰に売れて、お金はどの支払い方法に入ったか」を後から補うことができないからです。

:::warning アップグレード前にこの節を最後まで読んでください
- **商品マスタは自動で引き継がれます**：商品、カテゴリ、タグ、サークル、画像、AI 認識用の画像と認識データはすべて残ります。
- **古いイベント・注文・在庫は v1.2 には表示されません**。削除されたわけではなく、バックアップファイルにそのまま保存されていて、いつでも Excel に出力できます。
- **イベント当日や、イベントの途中でアップグレードしないでください。** 今のイベントを撤収し、売上レポートを出力してからアップグレードしましょう。
:::

## アップグレード手順

1. **進行中のイベントを先に締める**：v1.1 でそのイベントの売上レポートを出力します（「销售统计 → 下载 Excel」、売上統計 → Excel ダウンロード）。
2. **アプリを更新する**：
   - Windows（v1.1.1 以降）：「设置 → 关于与更新 → 检查更新」（設定 → アプリ情報と更新 → 更新を確認）から、ワンクリックでダウンロード・インストールできます。v1.1.0 はインストーラーを手動でダウンロードして上書きインストールする必要があります。[自動更新（中国語）](/guide/auto-update) を参照してください。
   - Android：[GitHub Releases](https://github.com/Academy-of-Boundary-Landscape/ABL-BoothApp/releases) から新しい APK をダウンロードして上書きインストールします（署名は変わらないので先にアンインストールする必要はありません。**むしろアンインストールしないでください**。アンインストールするとデータも一緒に消えます）。
3. **アプリを開いて管理画面にログインする**。古いデータベースにイベントや注文があれば、「**v1.2 更新了账本模型**」（v1.2 で帳簿モデルが更新されました）というお知らせが一度だけ表示されます。
   - **旧データを Excel に出力**（画面表示「导出旧数据为 Excel」）を押すと `legacy_v1_export.xlsx` が得られます。中身は旧バージョンのすべてのイベントと注文です。
   - **了解**（画面表示「知道了」）を押して閉じます。
4. 後でもう一度出力したくなったら、いつでも **設定 → 過去データ（v1）**（画面表示「设置 → 历史数据（v1）」）で「旧データを Excel に出力」を押してください。

## 古いデータはどこにある？

アップグレード時、古いデータベースは `sale_system.db.v1-backup` に **名前を変えて保存** され、新しいデータベースと同じフォルダに置かれます。

- Windows：`%APPDATA%\com.abl.BoothKernel\`
- Android：アプリのプライベートフォルダ。上記の「旧データを Excel に出力」からしか取り出せません

摊盒がこのファイルを自動で削除することはありません。

## アップグレード後にまずやること

1. **サークルの所属を確認する**。v1.2 では、すべての商品が 1 つの「サークル」（所有サークル・荷主）に属し、精算はサークルごとに分けて行います。
   自分の商品だけを頒布するなら何もしなくて大丈夫です。商品は初期設定ですべて「自サークル」（本社团）に属します。他のサークルの商品を委託販売する場合は、まず **サークル**（画面表示「社团」）ページで相手を作成し、
   **商品マスタ**（画面表示「商品库」）で相手の商品の「所属サークル」（所属社团）を変更してください。詳しくは [撤収と精算](./closing) を参照してください。
2. **新しいイベントで商品を出品する**。古いイベントは引き継がれないので、次のイベントでは新しくイベントを作成し、ワークベンチの「事前準備 · 商品」（展前 · 商品）で「商品マスタから選ぶ」（从商品库选）を使ってください。
3. **「マイナス価格の割引商品」を無効化する**。v1.1 では「-5 元の商品を作って割引にする」方法を紹介していましたが、v1.2 には正式な
   [セットと割引](./lots) と、会計時の「実受取額」（实收）の変更があります。マイナス価格の商品は統計を汚してしまうので、商品マスタで無効化してください。
4. **初期パスワードを変更する**。`admin123` / `vendor123` を変更するまで、管理画面の上部にずっと注意が表示されます。

## 今後のアップグレードでもデータはリセットされますか？

されません。今回のリセットは、帳簿モデルの世代交代に伴う一度きりの代償です。v1.2 からは、アップグレードの前にアプリが必ずデータベースのスナップショットを取り、
アップグレードに失敗すると自動で元に戻します。データベースの構造も追加方向の変更だけにとどめます。
