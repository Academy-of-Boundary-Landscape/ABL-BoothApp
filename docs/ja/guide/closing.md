# 撤収と精算

v1.2 から、イベントにははっきりした「終わり」があります。売り子が売り子画面で **撤収ウィザード** を最後まで進めると、システムが **精算書** を作成し、帳簿を凍結します。
精算書は「お金をどう分けるか」に答えるものです。各サークルの商品がどうなったか、それぞれいくら受け取るべきか、自分は誰にいくら送金すべきか。

:::warning 精算書の数字は帳簿から計算したもので、システムが照合したものではありません
摊盒は決済サービスと連携していません。「我应转给 XX」（XX へ送金すべき額）は **送金すべき金額** であって、送金済みという意味ではありません。「实际到手」（実際の受取額）は、あなたが自分で数えて入力したものです。
システムには入金を 1 件ずつ照合する手段がないので、送金したら記録は自分で残しておいてください。
:::

## まず押さえておくこと：サークル = 所有サークル（荷主）

すべての商品は 1 つの **サークル**、つまり荷主に属します。誰の商品が売れたかで、お金が誰のものかが決まります。

- **自サークル**（画面表示「本社团」）はただ 1 つ、あなた自身です。商品にサークルを指定しなければ、自サークルのものになります。
- 友人のサークルの商品を委託販売するときは、サイドバーの **サークル**（画面表示「社团」）で相手を新規作成し、**商品マスタ**（画面表示「商品库」）で相手の商品の **所属サークル**（画面表示「所属社团」）を相手に変更します。
- 「所属サークル」の変更が影響するのは **これから** イベントに出す商品だけです。すでに出品済みの商品は元の所属のままです。

自分の商品だけを頒布する方は、この節は気にしなくて大丈夫です。精算書には「自サークル」のブロックだけが表示されます。

## 当日：贈呈・廃棄・返品

この 3 つはどれも **売り子画面** で行い、そのまま帳簿に記録されて精算書にも反映されます。

### 贈呈と廃棄

商品が机の上から消えたけれど、売れたわけではない場合：売り子画面 → **在庫**（画面表示「库存」）→ **贈呈／廃棄を登録**（画面表示「登记赠送/报废」）。

- **贈呈**（画面表示「赠送」）：知り合いへの見本、ちょっとしたおまけなど。初期設定では **所有サークル自身の負担** で、精算書には何点贈ったかだけが表示されます。
  そのプレゼントが「自分のおごり」なら、**自腹で払う（定価で所有サークルに補填）**（画面表示「这笔我自掏（按原价补给货主）」）をオンにしてください。精算時にその金額があなたから所有サークルに補填されます。
- **廃棄**（画面表示「报废」）：破損・汚れ・欠品などで売れなくなったもの。在庫だけが動き、お金は動きません。

登録を間違えたら、下の一覧から **取り消し**（画面表示「撤销」）できます。商品は会場在庫に戻ります。

### 返品

売り子画面 → **注文**（画面表示「订单」）→ **完了済み**（画面表示「已完成」）→ 該当する注文を見つけて **返品**（画面表示「退货」）を押します。

- 注文の行ごとに、何点返品するかを選びます。同じ商品でもセットへの組み込み方によって 2 行に分かれていることがあり、どちらの行を返品するかはあなたが決めます。
- 行ごとに、返品された商品の行き先を選びます：**会場在庫に戻す（まだ売れる）**（画面表示「回现场仓（还能卖）」）または **ロスに計上（破損）**（画面表示「进损耗（已损坏）」）。
- **返金方法**（画面表示「退款渠道」）の初期値は受け取ったときの支払い方法と同じです。現金で受け取ったなら現金で返す。そうしないと入金照合が合わなくなります。
- **実返金額**（画面表示「实际退款」）の初期値は、選んだ行の実支払額の合計です。下げることはできますが、**お客様の実支払額を超えることはできません**。

**返品は取り消せません。** 間違えた場合は、逆向きの注文をもう一度作るか、精算時に精算調整を 1 件追加するしかありません。

## 撤収ウィザード：4 ステップ

イベントが終わったら、**売り子画面** で **撤収**（画面表示「收摊」）タブに切り替えます（スマホでは下部のタブバーにあります）。
ウィザードは 4 ステップを順番に進みます。今どのステップにいるかは帳簿の状態で決まるので、**途中で抜けても、別の端末から入り直しても進捗は消えません**。

### ① 注文の整理

**未処理**（画面表示「待处理」、お客様は注文済み・売り子がまだ受取確認していない）の注文が残っていると、後の 3 ステップには進めません。
1 件ずつ **完了**（画面表示「完成」、受取ダイアログが開きます）か **キャンセル**（画面表示「取消」）を押してください。残りが全部不要な注文だと確信できるなら、**すべてキャンセル**（画面表示「全部取消」）を押しても構いません。

:::warning このステップのボタンは押した瞬間に反映されます
「キャンセル」「すべてキャンセル」には確認ダイアログがありません。押す前によく確認してください。
:::

### ② 棚卸し（スキップ可）

各商品が会場に実際に何点残っているかを数えて、「実数」（画面表示「实数」）欄に入力します。

- 入力欄には **帳簿上の数量をあらかじめ入れていません**。「数えたら帳簿と同じだった」と「数えていない」は別物なので、同じだった場合もその数を入力してください。
- 上部に「已盘 X / Y」（棚卸し済み X / Y）が表示されます。**未入力のみ表示**（画面表示「只看未填」）をオンにすると、まだ入力していない行だけを表示できます。
- 途中で画面を切り替えても大丈夫です。入力済みの数字は、その端末に下書きとして残ります。
- 実数が帳簿と合わない場合、確定前に差異の一覧が表示されるので確認してください。**棚卸し差異は確定後に直接取り消すことはできません。**

どうしても棚卸しの時間がなければ **棚卸しをスキップ**（画面表示「跳过盘点」）を押します。精算書には「未盘点，剩余数为账面推算」（棚卸し未実施、残数は帳簿からの推定）と注記され、帳簿上の数を実数として扱うことはありません。

### ③ 持ち帰り

会場在庫に残っている商品をすべて持ち帰ることを確認し、**持ち帰りを確定**（画面表示「确认带回」）を押します。これで各商品の会場在庫がゼロになります。

### ④ 精算

まだ進行を妨げる問題（会場在庫が空になっていない等）があれば ⚠ で一覧表示され、**イベント終了**（画面表示「结束展会」）ボタンはグレーアウトしています。
問題がなければ「イベント終了」を押します。

- イベントの状態が **精算済み**（画面表示「已结算」）になり、帳簿が凍結されます。
- 「撤収」タブがそのままこのイベントの **精算書** に切り替わり、売り子画面から直接確認・出力できます。

## 精算書の見方

入口は 2 つあり、内容はまったく同じです。

- 管理画面：イベントワークベンチ → **撤収 · 精算**（画面表示「收摊 · 结算」）
- 売り子画面：精算済みイベントの **撤収**（画面表示「收摊」）タブ

<p style="text-align: center;"><img src="/images/v1.2/admin-settlement.png" alt="精算書：2 つの所有サークルのブロック" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>

所有サークルごとに 1 ブロックです。

| 行 | 意味 |
| --- | --- |
| 【货】（商品） | 持ち込み N → 販売 / 贈呈 / 廃棄 / 持ち帰り / 会場在庫、および棚卸し差異。「展开明细」（明細を開く）で商品ごとの内訳を表示 |
| 【钱】（お金） | 商品の定価 − セット値引き − 手動値引き（または + 手動値上げ）→ 純額。返品や自腹の贈呈があればここにも表示 |
| 【我垫付】（立替） | あなたがこのサークルのために立て替えたお金。送金すべき額から差し引かれます |
| 【调整】（調整） | 精算調整。項目ごとに一覧表示 |
| **我应转给 X**（X へ送金すべき額） | 最終的にこのサークルへ送金すべき金額 |

下部には「实际到手合计」（実際の受取額合計）「Σ 我应转给」（送金すべき額の合計）「摊主留存」（売り子の手元に残る額）の 3 つの合計が表示されます。

**Excel 出力**（画面表示「导出 Excel」）を押すと `settlement_<イベント名>.xlsx` が得られます。4 つのシートの説明は [エクスポートと振り返り](./export) を参照してください。

:::tip ページ上部に赤い警告バーが出たら
「这张结算单和账本对不上，先别急着导出」（この精算書は帳簿と一致しません。出力は少し待ってください）と出た場合、どこかの記帳が間違っています。まず確認するか、コミュニティのグループで報告し、問題ないと確かめてから出力してください。
:::

## 精算後に変更できること

凍結後は、注文・注文変更・補充・贈呈／廃棄・返品・棚卸し・持ち帰り・再精算はすべて拒否されます。
**3 つだけ** は、管理画面の「撤収 · 精算」（收摊 · 结算）で後から追記できます。

- **立替**（画面表示「垫付」）：あるサークルのために先に払ったお金（スペース代、印刷代など）。帰宅してから領収書を見て追記できます。「送金すべき額」から差し引かれます。
- **精算調整**（画面表示「结算调整」）：帰宅してから、誰かに多く渡すべき、または誰かから多くもらうべきお金があると気づいた場合。方向はボタンで「我要多给他们」（こちらが多く渡す）／「他们要多给我」（相手が多く渡す）を選び、金額は正の数だけを入力します。
- **入金照合**（画面表示「收摊清点」）：WeChat Pay／Alipay の明細と現金ボックスを見ながら、**使ったすべての支払い方法** の実際の受取額を入力します。
  帳簿との差額は売り子自身の負担となり、どの所有サークルの精算にも入りません。特定の所有サークルに負担してもらいたい場合は、精算調整を 1 件追加してください。

この 3 つは精算書を変えるので、精算書の下部には「账本最后变动于 …」（帳簿の最終更新日時）と表示されます。サークルに送る前に日時を確認し、最新のものであることを確かめましょう。

:::danger イベントの削除は凍結で守られません
イベント一覧で精算済みのイベントを削除すると、そのイベントのすべての注文と帳簿の記録もまとめて **完全に削除され、復元できません**。
照合用に残しておきたいイベントは削除しないでください。
:::
