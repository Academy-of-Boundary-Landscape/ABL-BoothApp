# 推荐工作流

摊盒（BoothKernel）不仅仅是一个记账软件，它背后是一个我们比较推荐的标准工作流。

:::warning ⚠️ 核心原则：关于资金安全
**摊盒是一个辅助点单与库存管理的工具，它不直接处理资金流。**
我们的支付逻辑是“显示摊主个人的微信/支付宝收款码”。我们无法也不会介入你的资金流转。
这意味着：App 里面的“订单已完成”仅代表**记录了一笔账**，不代表钱真的到了你的账户。
**结算单上的「我应转给 XX」是账本算出来的应转数，不是已经转过；「实际到手」是你自己数出来录进去的，系统没有能力核对任何一笔到账。**
*   请务必在**手机确认收到**微信/支付宝/现金的到账提醒后，再在 App 上点击确认。
*   建议开启微信/支付宝的“语音播报”功能，以辅助确认。
:::

## 展前准备

在出发去漫展之前，在家里的舒适环境下完成这些配置，不要去现场浪费时间。

### 1. 录入商品与库存
*   **商品库**：把所有制品的编号、名称、价格、图片录进「商品库」。帮别的社团代卖的，把「所属社团」设成对方（先在「社团」页建好），结算时自动分开算。
*   **上架与库存**：新建展会，进入展会工作台，在「展前 · 商品」里「从商品库选」或「从上一场导入」，填好这次带去的库存（例如：新刊 x100，立牌 x50）。现场不够了可以随时「补货」。
*   **配置收款码**：
    *   在新建 / 编辑展会时上传你的**微信 / 支付宝收款码图片**。
    *   顾客下单后平板会直接展示二维码，省去你指着桌上贴纸的动作。

:::tip 关于制品录入
你可以在「商品库」页面把制品数据（编号、名称、价格、图片）导出成一个 `.boothpack` 文件。
如果要托付合作者帮你出摊，把这个文件发给他们直接导入，省去重复录入。
:::


### 2. 关于“套装 (Set)”的处理策略
:::tip 💡 套装按你「打不打包」来录
如果您售卖包含多个单品的套装（如：新刊套装 = 1本子 + 1挂件），请根据您的**打包习惯**选择以下两种录入方式之一，以保证库存准确：
:::

*   **方式 A：物理预打包（推荐）**
    *   *场景*：您在展前已经把本子和挂件装进袋子里封好了。
    *   *操作*：在 App 里新建一个商品叫**“新刊套装”**，库存设为实际打包的数量（如 50 份）。
    *   *逻辑*：把它当作一个独立的商品来卖，卖一个扣一个。
*   **方式 B：现场凑单 + 套装优惠**
    *   *场景*：您没有提前打包，是顾客买了套装后，您现场拿一本本子、拿一个挂件。
    *   *操作*：分别录入单品“新刊”和“挂件”，再到展会工作台的 **「展前 · 套装」** 里配一个「固定组合」套装：候选商品选这两样、要选 2 件、填上打包价。详见[套装与优惠](./lots)。
    *   *逻辑*：顾客在点单界面分别点“新刊”和“挂件”，购物车会自动套用这个套装并写明省了多少。单品的库存仍然精准扣减。
    *   *注意*：**套装的候选商品必须属于同一个货主。** 帮别的社团代卖的商品不能和自己的本子凑进同一个套装——那等于替他们让价。

### 3. 模拟演练 
*   准备好你要带去现场的所有设备（手机、平板）。
*   **断网测试**：关闭路由器，让手机开热点，确保平板能连上并正常点单。
*   **电量焦虑**：确保所有设备充满电，并准备好**充电宝**（这一点非常重要！）。
*   **流程预演**：让你的朋友/路人假装是顾客，模拟一遍点单、支付、记录收款方式、交货的完整流程，确保你熟悉每个步骤。

## 展中执行 

现场最重要的是**效率**和**准确**。

### 1. 快速开摊
1.  **开热点**：用一台手机开启 Wi-Fi 热点，主机、平板、摊主手机都连上它。
2.  **启动主机**：主机打开摊盒 App，进入「设置 → 局域网连接」，点「获取局域网二维码」。
3.  **连接设备**：平板扫「顾客入口」、摊主手机扫「摊主入口」，进入这场展会。
4.  **摆放设备**：将平板立在摊位最显眼处，作为“电子菜单”。

:::tip
### 小贴士：如何引导顾客使用自助点单？
有时候顾客可能会习惯性地直接询问，而忽略了平板的存在。以下几个小技巧可以让“自助点单”更顺畅：

1.  **物理引导**：
    *   **贴标签**：在平板边框或支架上贴一张醒目的便利贴，写上 **“👈 点我查看制品 / 戳屏幕下单”**。
    *   **摆放位置**：把平板放在顾客视线最自然的落点（通常是摊位正前方靠右的位置），而不是藏在货物后面。

2.  **话术引导**：
    *   当顾客靠近时，主动说：“您好，**可以在平板上滑一滑**，有大图和价格哦。”
    *   当顾客询问“这个多少钱”时，指引说：“平板上点了可以直接算总价，您可以试试。”

3.  **展示模式**：
    *   在没人点单时，确保平板停留在**商品列表的最顶端**，或者展示着最热门的新刊封面，不要让屏幕停留在结算页或黑屏。
:::

### 2. 标准接单流程

请养成肌肉记忆，遵循以下 4 步循环：

#### 第一步：顾客自助点单
*   引导顾客在平板上浏览。
*   顾客选好商品，点击**「去结算」→「确认下单」**。有套装优惠时，购物车会自动套用并写明省了多少。
*   平板屏幕弹出**「请扫码支付 ¥85」**以及你的收款码，同时显示单号。

#### 第二步：支付与配货 (并行进行) 
这是效率提升的关键！
*   **摊主（你）**：看到手机弹出的“新订单提醒”，立刻转身从纸箱里拿出对应的商品。
*   **顾客**：同时掏出手机扫描平板上的码付款。

#### 第三步：确认收款
*   **听/看**：等待你的手机响起“支付宝到账”提示音，或看一眼顾客展示的支付成功界面。
*   **点**：在摊主端这张订单上点**「完成配货」**，弹出「确认收款」：
    *   选**收款渠道**（微信 / 支付宝 / 现金 / 其他），收摊时按渠道对账；
    *   顾客不要某个套装，可以在这里拆掉；抹零、让价就直接改「**实收**」；
    *   点「**确认收款 ¥xx**」。
*   **注意**：这一步只是**记账**，不代表 App 验证过钱是否真的到账。

#### 第四步：交付与完成
*   将配好的商品递给顾客。
*   库存在顾客下单时就已经扣减，这一单到此结束，准备接待下一位。

:::tip 帮顾客点单 / 扫码加购
顾客不想自己点时，摊主端点「**去点单**」进入点单页代点，点完点「**回摊主端**」。
商品有条码的话，点单页的「▦ 扫码」能连续扫码加购，也可以直接用扫码枪，见[条码扫描](./barcode-scan)。
:::


### 3. 清点余量

摊主端的「**库存**」tab 显示各制品的现场仓余额，它是按目前所有订单、退货、赠送、报废推算出来的数量。

货不在摊上、但不是卖掉的（送人、弄坏了），在「库存」tab 点「**登记赠送/报废**」记上，否则收摊盘点时会对不上。

:::tip
一个好习惯：在收摊之前手动清点实际的库存数量，并和App上的数据进行对比，看看是否有差异。
如果有，请务必找出差异的原因（如漏记订单、误操作等），以便下次改进流程。
:::

### 4. 退货

顾客拿着货回来退时，在**摊主端 → 已完成**列表里找到那笔订单，点「退货」：

*   弹窗按**订单行**逐行列出（同一个商品因为套装归属可能拆成多行），退哪一行、退几件由你决定，不是系统猜的。
*   每行可以选退回来的去向：**回现场仓**（还能再卖）或**进损耗**（已经损坏）。
*   **退款渠道默认和收款渠道相同**。现金收的就选现金退，否则收摊清点时两边对不上；改成别的渠道也可以，但两个渠道的账户会各自变动。
*   退款金额默认按所选各行的实付合计。退得比实付少时，差额留在货主账上（退的是顾客没拿走的那部分）；**不能退得比顾客实付更多**——白送钱请走结算调整。

已经退完的行会标一个**「已退完」**，避免重复退。**退货一旦提交没有撤销**，退错了的补救办法是再开一张反向的单或走结算调整。

赠送、报废、退货对结算的影响见[收摊与结算](./closing)。

## 收摊

一场展结束、准备撤展时，在**摊主端**切到「收摊」tab，跟着向导走四步：

1.  **清点订单**：先把还没确认的订单逐单完成或取消，否则后面进不去。
2.  **盘点**（可以跳过）：把每个品种实际剩多少件数一遍填进去，和账面不一致的记成盘点差异。没盘点的场次，结算单会标注「未盘点，剩余数为账面推算」。
3.  **带回**：确认剩下的货全部带走。
4.  **结算**：点「结束展会」，账本冻结，「收摊」tab 原地变成这场的结算单。

冻结之后只有**垫付、结算调整、收摊清点**三件事还能回家补。每一步的细节、结算单怎么看，见[收摊与结算](./closing)。

:::warning 注意：删除展会不受冻结保护
在展会列表里删除一场已结算的展会，会连同它的全部订单和账本流水一起**永久删除，无法恢复**。想留着对账的展会，不要删。
:::

## 展后复盘

收摊后，数据是你最宝贵的资产。

### 1. 快速对账
在撤展的路上或回酒店后：
*   打开管理后台，进入这场展会的 **「收摊 · 结算」**。
*   在 **「收摊清点」** 里，对着微信 / 支付宝的「今日账单」和手里的现金，把每个收款渠道的实际到手填进去。
*   系统会算出每个渠道的**账面应有**和**差额**。几块钱的误差很常见；大额出入可以导出结算单，在「账本流水」和「订单明细」里逐笔排查。

### 2. 导出报表
两个导出回答两个不同的问题，按需要选：
*   **销售汇总**（展会工作台 → 现场 · 统计 → 下载 Excel 报告）：回答「**卖了什么**」——各商品的销量和销售额，适合当成绩单发群里或展后复盘。
*   **结算单**（展会 → 收摊 · 结算 → 导出 Excel；摊主端「收摊」tab 同样可导出）：回答「**账怎么算**」——每个货主该分多少、我该转给谁多少、各收款渠道的账面和实际差多少。**寄售分账看的是这一份，不是销售汇总。**
*   两者都把金额写成「元、两位小数」，可以直接导入社团的财务系统。

### 3. 数据备份
*   展会数据只存在主机上。每场结束后导出一份结算单和销售汇总留底，防止设备丢失。
*   商品库在「商品库」页底部导出 `.boothpack` 备份。

## 额外的小贴士

*   **关于 iPad 防盗**：虽然平板放在外面很方便，但如果人流过大，建议使用**防盗支架/锁**，或者定期间歇性地把平板收回来。
*   **关于现金**：即使是电子支付时代，也请准备 200 元左右的零钱（10元/5元），以防万一。
*   **关于心态**：技术是工具，你是主人。如果现场实在太乱，App 连不上了，**立刻切回纸笔记录**，不要在修 Bug 上浪费做生意的时间。
