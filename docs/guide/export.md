# 导出与复盘

摊盒的导出分三类，用途完全不同：

- **销售汇总**（CSV / Excel）：回答「卖了什么」，给展后复盘、成绩单；
- **结算单**（`settlement_<展会名>.xlsx`）：回答「账怎么算」，给货主分账和收款清点；
- **商品包 `.boothpack`**：迁移商品库，不包含任何展会 / 订单数据；
- **历史数据（v1）**：从 v1.1 升级上来的用户，旧版的展会和订单可以导出成 Excel。

下面分别说明入口、格式和用途。

:::warning ⚠️ `.boothpack` 不是全量备份
`.boothpack` **只包含商品库（名称、价格、编号、图片）**，**不包含展会、订单和销售流水**。
如果你把它当成"导出了就等于备份了这一场展"，展后想找销售数据会发现根本不在里面。
展会数据可以导出成 Excel（销售汇总和结算单），但**导出的表格不能导回 App**；换设备或清空数据之前，请另行备份设备上的数据库文件。
:::

## 销售汇总：CSV / Excel

用于展后复盘，或者把成绩单交给社团主催核对分账。

**入口**：侧边栏「展会」→ 进入某场展会 → 「现场 · 统计」，有销售数据时页面右上角有两个按钮：

- **下载 CSV**：纯文本表格，字段为「制品编号、制品名、单价、销售量、销售额」，
  适合导入 Excel / 飞书表格 / Numbers 二次处理，或者贴进群聊里发个成绩单。
- **下载 Excel 报告**：`.xlsx` 格式，带展会名称、生成时间和表格样式，可以直接打印或
  发给社团主催，不需要再排版。

两者的数据来源相同（当前筛选条件下的销售汇总），区别只是文件格式和是否带格式化。
如果你在页面上方设置了制品筛选或时间范围，导出的内容会跟着筛选结果走。

## 结算单：`settlement_<展会名>.xlsx`

销售汇总回答的是「**卖了什么**」；结算单回答的是「**账怎么算**」——每个货主该分多少、我该转给谁多少、每个收款渠道的账面和实际差多少。**寄售分账看的是这一份。**

**入口**：侧边栏「展会」→ 进入某场展会 → 「收摊 · 结算」，结算单右上角「导出 Excel」；摊主在摊主端的「收摊」tab 里也能看到并导出同一张结算单。结算单要先把收摊向导走完（清点订单 / 盘点 / 带回 / 结算）才完整——第一步得**先把 pending 订单逐单完成或取消**，否则向导卡在第一步；没盘点过的场次会在表头明确标注「未盘点，剩余数为账面推算」。

<p style="text-align: center;"><img src="/images/v1.2/admin-settlement.png" alt="结算单页面" style="width: 100%; border-radius: 8px; border: 1px solid var(--vp-c-divider);"></p>

一个 `settlement_<展会名>.xlsx` 里有四个 sheet：

| Sheet | 里面是什么 | 社团拿到该看哪一列 |
| --- | --- | --- |
| **结算汇总** | 每个货主的商品原价、套装折让、手工折让、净额、退货保留、自掏赠品、垫付、调整，以及最后的「我应转给」；下面还列出各收款渠道的账面 / 实际 / 差额 | 「**我应转给**」——这是账本算出来的应转数。垫付和调整逐条列了名目，看不懂某笔就从这里对 |
| **货主明细** | 按货主 × 商品列出带去 / 卖出 / 赠送 / 报废 / 差异 / 带回 / 现场仓，以及这一行的原价 / 折让 / 净额 | 「**净额**」——这个商品的成交价（已扣套装折让和退货），社团财务按这一列记账 |
| **账本流水** | 每个 journal 的时间、种类、订单号、摘要，以及这一笔的货腿和钱腿 | 要查「这笔钱是怎么记的」时看这里；一条 journal 就是一次不可再分的记账 |
| **订单明细** | 每张订单每一行的商品、套装、件数、单价、货主应得、顾客实付、已退件数 | 要对某笔订单时看「**顾客实付**」和「**已退件数**」 |

:::warning ⚠️ 结算单上的「我应转给」不是「已经转过」
那是账本算出来的应转数。**系统没有能力核对任何一笔到账**：它不接支付接口，「实际到手」也是摊主自己数出来录进去的。转完账请自己留好凭证。

另外，结算单会随冻结后的补录（垫付 / 结算调整 / 收摊清点）更新，导出前看一眼表头的「最后更新于」，确认手里这份是最新的。
:::

## 商品包：`.boothpack`

用于**换设备**或**多人协作出摊**时迁移商品库，省去在新设备上重新逐个录入商品的麻烦。

**入口**：侧边栏「商品库」页面，往下有一个「商品数据包（.boothpack）」面板：

- **导出 .boothpack**：把当前所有商品的编号、名称、价格、分类、标签、商业条码、所属社团，以及
  商品预览图和 AI 识别用的参考图片，打包成一个 `.boothpack` 文件（本质是 zip 压缩包）。
- **导入 .boothpack**：把 `.boothpack` 文件拖进面板，或者点击导入按钮选择文件。

**典型用途**：

- 你已经在自己的电脑上录好了这一场展的全部商品，出摊那天用平板收银——
  导出后把文件传到平板上导入，不用在平板上重新敲一遍。
- 你要把商品库托付给合作者帮忙出摊，把 `.boothpack` 发给对方，对方导入后
  商品数据和你这边一致。

:::tip 导入会覆盖同编号商品
导入 `.boothpack` 时，如果目标设备上已经存在相同商品编号的商品，会被导入的数据覆盖。
建议在导入前先导出一份当前数据作为备份，避免误覆盖。
:::

## 历史数据（v1）

v1.2 换了新账本，旧版的展会和订单没有迁移进来，而是原样保留在备份文件 `sale_system.db.v1-backup` 中。

**入口**：升级后第一次登录管理后台时弹出的提示框；或者随时在「**设置 → 历史数据（v1）**」点「**导出旧数据为 Excel**」。
导出文件是 `legacy_v1_export.xlsx`，有「展会」「订单」「订单明细」三个 sheet，包含旧版的全部展会和订单。

没有旧数据的设备（全新安装）不会显示这一块。详见[从 v1.1 升级到 v1.2](./upgrade-v1.2)。
