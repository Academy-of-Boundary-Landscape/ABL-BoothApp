# 画像表示

画像は「お客様が注文してくれるかどうか」を左右する大事な要素ですが、元画像のサイズで痛い目を見やすいところでもあります。

## 商品画像が表示されない／読み込みが遅い

次の順に対処してください。

1. 画像のファイル名に特殊な記号が含まれていないか確認（**数字か英字のみ** の名前がおすすめ）
2. LAN の転送帯域には限りがあるので、1 枚あたり **500KB 以内** に圧縮するのがおすすめです
   10MB の高解像度の元画像をそのままアップロードするのはやめましょう（当日つらいことになります）

## 画面の見た目をカスタマイズできますか？

**設定 → 外観**（画面表示「设置 → 外观」）で次の項目を調整できます。

- **表示モード**（画面表示「界面模式」）：ライト／ダーク
- **商品画像の比率**（画面表示「商品图比例」）：3:4 の縦長か 1:1 の正方形。注文画面のカードの比率と、画像アップロード時のデフォルトのトリミングに影響します
- **ブランドカラー**（画面表示「品牌主色」）：いくつかのプリセット配色

注文画面右上の「⚙」からは、商品カードの大きさを変えたり、ドラッグで商品の並び順を変えたりできます（並び順はその端末にだけ保存されます）。
